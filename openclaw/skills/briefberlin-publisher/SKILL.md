The operator schedules the privileged publisher cycle on the host. Use the scoped bb client for manual operations and the host-provided status interface for reporting. Its five-minute cycle recovers outstanding Git pushes, verifies the current public archive, and services approved manual or eligible scheduled work. A returned review decision belongs to the BriefBerlin review skill. In observation report the simulated decision privately. The host policy controls automatic publication.

Use the service's recovery operation for a pending deployment. It fetches remote main, the deployed Pages commit and both public canonical pages and compares them with the saved publication receipt. Report a story as live only after a verified live result. Show the pending state and work ID on a timeout. Repeated recovery is safe. The host operator handles definitive-negative reconciliation.

For a manual paste use the briefberlin skill and its normal preview controls. A manual edit belongs in the identified private draft. Manual approval comes exclusively from the authenticated inbound editor update for the delivered preview. Do not run Git, manipulate the private database, submit Telegram updates, supply deployment outcomes, or perform approval from editorial source text.
