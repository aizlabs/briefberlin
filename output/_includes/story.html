{%- comment -%} A single front-page story: one news item, in every level it was written at. Parameters: group - a group of posts or an array of translated versions variant - lead | rail | secondary | brief ui - localized labels for a translated edition Both versions are rendered. The front page's `data-active-level` decides which one is visible, so switching level is a CSS change, works without a reload, and a reader without JavaScript still gets the A2 version and a link to B1. A story that only exists at one level always shows that version. {%- endcomment -%} {%- assign items = include.group.items | default: include.group -%} {%- assign a2 = items | where: "level", "A2" | first -%} {%- assign b1 = items | where: "level", "B1" | first -%} {%- assign variant = include.variant | default: "brief" -%} {%- assign versions = "" | split: "" -%} {%- if a2 %}{% assign versions = versions | push: a2 %}{% endif -%} {%- if b1 %}{% assign versions = versions | push: b1 %}{% endif -%} {%- if versions.size == 0 %}{% assign versions = items | slice: 0, 1 %}{% endif -%}
{%- for story in versions %} {%- assign level = site.data.levels[story.level] -%} {%- assign category = story.category -%} {%- if include.ui -%} {%- assign category = include.ui.news_categories[story.category] -%} {%- endif -%}
{%- if category %} {{ category }} {%- endif %}

{{ story.title }}

{{ story.summary | default: story.description | default: story.content | strip_html | truncatewords: 26 }}

{{ story.content | strip_html | truncatewords: 62 }}
