Der <button type="button" class="article-term" data-term-id="term-1">Hackerangriff</button> auf die Berliner <button type="button" class="article-term" data-term-id="term-2">Landesverwaltung</button> hat größere <button type="button" class="article-term" data-term-id="term-3">Folgen</button> als <button type="button" class="article-term" data-term-id="term-4">bisher</button> bekannt. Im vergangenen August <button type="button" class="article-term" data-term-id="term-5">stahlen</button> Kriminelle rund 5,79 Terabyte Daten aus den Senatsverwaltungen für Verkehr und für Bauen. Nach <button type="button" class="article-term" data-term-id="term-6">Ablauf</button> einer <button type="button" class="article-term article-term--default" data-term-id="term-7">Frist</button> veröffentlichten sie die Daten im Darknet, einem <button type="button" class="article-term" data-term-id="term-8">versteckten</button> Teil des Internets. Darunter sind 9708 <button type="button" class="article-term" data-term-id="term-9">Anträge</button> auf <button type="button" class="article-term article-term--default" data-term-id="term-10">Mietzuschuss</button> für <button type="button" class="article-term" data-term-id="term-11">Sozialwohnungen</button> aus der Zeit von 2016 bis Anfang 2020. Dazu kommen 2824 <button type="button" class="article-term" data-term-id="term-12">Folgeanträge</button> und 1667 <button type="button" class="article-term" data-term-id="term-13">Änderungsanträge</button>. Weil auch Partner, Kinder und andere <button type="button" class="article-term" data-term-id="term-14">Haushaltsmitglieder</button> genannt sind, sind insgesamt 16.858 Menschen <button type="button" class="article-term" data-term-id="term-15">betroffen</button>. Das sind wohl fast alle <button type="button" class="article-term" data-term-id="term-16">Antragsteller</button> aus dieser Zeit.

<aside>Mehr dazu: <a href="{% post_url 2026-11-25-140431-hackerangriff-auf-berliner-verwaltung-daten-von-ue-b1 %}">Was die spätere Analyse über das Ausmaß des Datendiebstahls zeigt</a></aside>

Von fast allen Antragstellern sind Name, <button type="button" class="article-term" data-term-id="term-17">Geburtsdatum</button> und Adresse <button type="button" class="article-term" data-term-id="term-18">sichtbar</button>. Bei zwei Dritteln kann man außerdem <button type="button" class="article-term" data-term-id="term-19">Familienstand</button>, Miete und <button type="button" class="article-term" data-term-id="term-20">Haushaltseinkommen</button> lesen. Dazu kommen Bankdaten von rund 4000 Personen, etwa 6400 Telefonnummern und über 700 E-Mail-Adressen. Bei 2423 Menschen stehen Informationen über eine schwere <button type="button" class="article-term" data-term-id="term-21">Behinderung</button>, teilweise auch über <button type="button" class="article-term article-term--default" data-term-id="term-22">Pflegebedürftigkeit</button>. Besonders <button type="button" class="article-term article-term--default" data-term-id="term-23">heikel</button> sind Textfelder, in denen die Menschen erklären mussten, warum ihre Wohnung größer ist als <button type="button" class="article-term" data-term-id="term-24">gesetzlich</button> erlaubt. Viele berichten dort von <button type="button" class="article-term" data-term-id="term-25">Trennungen</button>, Depressionen, <button type="button" class="article-term" data-term-id="term-26">Fehlgeburten</button>, <button type="button" class="article-term" data-term-id="term-27">Todesfällen</button> oder der <button type="button" class="article-term" data-term-id="term-21">Behinderung</button> ihrer Kinder. Die Texte zeigen auch, wie schwierig die Lage auf dem Berliner <button type="button" class="article-term" data-term-id="term-28">Wohnungsmarkt</button> ist. Ein <button type="button" class="article-term" data-term-id="term-29">alleinstehender</button> Mann <button type="button" class="article-term" data-term-id="term-30">fürchtet</button> zum Beispiel, ohne die Wohnung <button type="button" class="article-term article-term--default" data-term-id="term-31">obdachlos</button> zu werden.

<button type="button" class="article-term" data-term-id="term-32">Offenbar</button> war eine einzige E-Mail der Grund für das Problem. Anfang 2020 <button type="button" class="article-term" data-term-id="term-33">übernahm</button> die Investitionsbank Berlin-Brandenburg die <button type="button" class="article-term" data-term-id="term-34">Bearbeitung</button> der <button type="button" class="article-term" data-term-id="term-9">Anträge</button> von einer anderen Firma. Ein <button type="button" class="article-term" data-term-id="term-35">Bote</button> brachte die Daten damals auf externen <button type="button" class="article-term" data-term-id="term-36">Festplatten</button> zur Bank. Wenige Wochen später schickte ein Mitarbeiter der Senatsverwaltung für <button type="button" class="article-term" data-term-id="term-37">Stadtentwicklung</button> und Wohnen drei Excel-Tabellen mit den Daten an einen Kollegen. Dieser arbeitete im selben Haus, und warum er die Daten bekam, ist bis heute <button type="button" class="article-term" data-term-id="term-38">unklar</button>. <button type="button" class="article-term" data-term-id="term-39">Zunächst</button> blieb auch offen, ob die Senatskanzlei das <button type="button" class="article-term" data-term-id="term-40">Ausmaß</button> kennt und die Betroffenen schon informiert hat.

Der Fall hat wahrscheinlich <button type="button" class="article-term" data-term-id="term-41">rechtliche</button> <button type="button" class="article-term" data-term-id="term-3">Folgen</button>. Experten sehen einen schweren <button type="button" class="article-term article-term--default" data-term-id="term-42">Verstoß</button> gegen die <button type="button" class="article-term" data-term-id="term-43">Datenschutz-Grundverordnung</button>, das EU-Gesetz zum Schutz persönlicher Daten. Eine Berliner <button type="button" class="article-term" data-term-id="term-44">Anwältin</button> für Datenschutz glaubt, dass Betroffene mehrere tausend Euro <button type="button" class="article-term article-term--default" data-term-id="term-45">Schadensersatz</button> <button type="button" class="article-term" data-term-id="term-46">fordern</button> können. Das gilt für jedes Haushaltsmitglied <button type="button" class="article-term" data-term-id="term-47">einzeln</button>, deshalb können Familien schnell über 10.000 Euro erreichen. Je sensibler die Daten sind, desto höher ist der <button type="button" class="article-term" data-term-id="term-48">Anspruch</button>. Die <button type="button" class="article-term" data-term-id="term-49">Geschädigten</button> können sich außerdem <button type="button" class="article-term" data-term-id="term-50">zusammentun</button> und gemeinsam <button type="button" class="article-term" data-term-id="term-51">klagen</button>. Trotzdem kann Geld den Verlust der <button type="button" class="article-term" data-term-id="term-52">Privatsphäre</button> wohl kaum <button type="button" class="article-term" data-term-id="term-53">ausgleichen</button>.
