Der <button type="button" class="article-term" data-term-id="term-2">Unternehmer</button> Hamid Djadda hat im März 2024 in der Buddestraße in Berlin-Tegel einen alten <button type="button" class="article-term article-term--default" data-term-id="term-1">Tanzsaal</button> <button type="button" class="article-term article-term--default" data-term-id="term-3">freilegen lassen</button>. Djadda <button type="button" class="article-term" data-term-id="term-4">besitzt</button> das <button type="button" class="article-term" data-term-id="term-5">Gebäude</button> seit 13 Jahren. Hinter der einfachen <button type="button" class="article-term" data-term-id="term-6">Straßenfront</button> kam ein Raum <button type="button" class="article-term" data-term-id="term-7">hervor</button>, den viele Menschen lange <button type="button" class="article-term" data-term-id="term-9">nicht mehr</button> <button type="button" class="article-term" data-term-id="term-8">kannten</button>. Der Saal ist <button type="button" class="article-term" data-term-id="term-10">rund</button> 125 Jahre alt und soll wieder <button type="button" class="article-term article-term--default" data-term-id="term-11">Kulturleben</button> <button type="button" class="article-term" data-term-id="term-49">erhalten</button>.

Der historische Raum hat etwa 400 Quadratmeter Fläche. Er <button type="button" class="article-term" data-term-id="term-4">besitzt</button> <button type="button" class="article-term article-term--default" data-term-id="term-12">Emporen</button>, also <button type="button" class="article-term" data-term-id="term-13">erhöhte Bereiche</button> an den Seiten für Besucher. Besonders <button type="button" class="article-term" data-term-id="term-14">auffällig</button> ist die Kassettendecke. Das ist eine <button type="button" class="article-term" data-term-id="term-15">kunstvoll</button> <button type="button" class="article-term" data-term-id="term-16">gestaltete</button> Decke mit vielen <button type="button" class="article-term" data-term-id="term-17">Feldern</button> und <button type="button" class="article-term" data-term-id="term-18">Mustern</button>. Solche Details zeigen, dass der Saal <button type="button" class="article-term" data-term-id="term-19">früher</button> ein wichtiger Ort für <button type="button" class="article-term" data-term-id="term-20">Feste</button> und Tanz war.

Lange konnte man die Größe des Saales <button type="button" class="article-term" data-term-id="term-21">kaum erkennen</button>. Eine <button type="button" class="article-term article-term--default" data-term-id="term-22">Zwischendecke</button> <button type="button" class="article-term" data-term-id="term-23">teilte</button> den Raum und <button type="button" class="article-term" data-term-id="term-24">verdeckte</button> die <button type="button" class="article-term" data-term-id="term-25">ursprüngliche</button> Höhe. Diese <button type="button" class="article-term" data-term-id="term-26">eingebaute</button> zweite Decke machte aus dem großen Saal einen viel <button type="button" class="article-term" data-term-id="term-27">niedrigeren</button> Raum. <button type="button" class="article-term" data-term-id="term-28">Deshalb</button> <button type="button" class="article-term" data-term-id="term-29">verschwand</button> seine besondere Form <button type="button" class="article-term article-term--default" data-term-id="term-30">aus dem Blick</button> der <button type="button" class="article-term" data-term-id="term-31">Öffentlichkeit</button>. Viele <button type="button" class="article-term" data-term-id="term-32">Passanten</button> sahen nur die <button type="button" class="article-term" data-term-id="term-33">unauffällige</button> Fassade an der Buddestraße.

<button type="button" class="article-term" data-term-id="term-34">Zeitweise</button> <button type="button" class="article-term" data-term-id="term-35">nutzte</button> im <button type="button" class="article-term article-term--default" data-term-id="term-36">Erdgeschoss</button> eine <button type="button" class="article-term" data-term-id="term-37">Filiale</button> der Kette Mäc-Geiz die Räume. Mäc-Geiz ist ein Geschäft, das <button type="button" class="article-term" data-term-id="term-38">günstige</button> <button type="button" class="article-term" data-term-id="term-39">Waren</button> für den <button type="button" class="article-term" data-term-id="term-40">Alltag</button> <button type="button" class="article-term" data-term-id="term-41">verkauft</button>. <button type="button" class="article-term" data-term-id="term-42">Dadurch</button> <button type="button" class="article-term" data-term-id="term-43">wirkte</button> das <button type="button" class="article-term" data-term-id="term-5">Gebäude</button> <button type="button" class="article-term" data-term-id="term-44">eher</button> wie ein normaler <button type="button" class="article-term" data-term-id="term-45">Laden</button>. <button type="button" class="article-term" data-term-id="term-46">Trotzdem</button> <button type="button" class="article-term" data-term-id="term-47">blieb</button> <button type="button" class="article-term" data-term-id="term-48">darüber</button> ein Teil der alten Geschichte <button type="button" class="article-term" data-term-id="term-49">erhalten</button>. Erst als Djadda den Saal im März freilegen ließ, wurde seine <button type="button" class="article-term" data-term-id="term-50">frühere</button> Dimension wieder <button type="button" class="article-term" data-term-id="term-51">sichtbar</button>.

Für Tegel ist der <button type="button" class="article-term" data-term-id="term-52">Fund</button> mehr als eine <button type="button" class="article-term" data-term-id="term-53">bauliche</button> <button type="button" class="article-term" data-term-id="term-54">Überraschung</button>. Der <button type="button" class="article-term article-term--default" data-term-id="term-1">Tanzsaal</button> <button type="button" class="article-term" data-term-id="term-55">erinnert an</button> eine Zeit, in der solche Räume wichtige <button type="button" class="article-term article-term--default" data-term-id="term-56">Treffpunkte</button> im <button type="button" class="article-term" data-term-id="term-57">Stadtteil</button> <button type="button" class="article-term" data-term-id="term-39">waren</button>. Nun soll der lange <button type="button" class="article-term" data-term-id="term-58">vergessene</button> Ort wieder stärker <button type="button" class="article-term" data-term-id="term-59">beachtet</button> werden. Wenn er neues <button type="button" class="article-term article-term--default" data-term-id="term-11">Kulturleben</button> bekommt, könnte er <button type="button" class="article-term" data-term-id="term-60">erneut</button> ein <button type="button" class="article-term" data-term-id="term-61">öffentlicher</button> Treffpunkt werden.
