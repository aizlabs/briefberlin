Konflikt um das <button type="button" class="article-term" data-term-id="term-1">Mandat</button>
Die Berliner Linke hat den <button type="button" class="article-term" data-term-id="term-2">Streit</button> mit Vanessa Emde aus Neukölln <button type="button" class="article-term article-term--default" data-term-id="term-3">verschärft</button>. Am Freitagabend <button type="button" class="article-term" data-term-id="term-4">forderte</button> die Berliner <button type="button" class="article-term" data-term-id="term-5">Parteileitung</button> sie auf, ihren <button type="button" class="article-term" data-term-id="term-6">Sitz</button> im Abgeordnetenhaus <button type="button" class="article-term" data-term-id="term-7">abzugeben</button>. Das ist das Berliner Landesparlament. Sie sprach von starkem <button type="button" class="article-term article-term--default" data-term-id="term-8">Vertrauensverlust</button>.

<button type="button" class="article-term" data-term-id="term-9">Vorwürfe</button> der Partei
Die Linke sagt: Emde hat <button type="button" class="article-term" data-term-id="term-10">mehrmals</button> gegen gemeinsame <button type="button" class="article-term" data-term-id="term-11">Beschlüsse</button> <button type="button" class="article-term article-term--default" data-term-id="term-12">verstoßen</button>. Außerdem hielt sie eine <button type="button" class="article-term" data-term-id="term-13">Vereinbarung</button> für <button type="button" class="article-term" data-term-id="term-14">gewählte</button> <button type="button" class="article-term" data-term-id="term-15">Abgeordnete</button> nicht ein. Diese hatte sie vor der Wahl mit der Partei unterschrieben. Darin steht, dass <button type="button" class="article-term" data-term-id="term-15">Abgeordnete</button> das Partei- und <button type="button" class="article-term" data-term-id="term-16">Wahlprogramm</button> respektieren sollen.

<button type="button" class="article-term" data-term-id="term-2">Streit</button> über Israel
<button type="button" class="article-term article-term--default" data-term-id="term-17">Auslöser</button> waren mehrere öffentliche <button type="button" class="article-term" data-term-id="term-18">Aussagen</button> von Emde. Kritiker in der Partei und mögliche Regierungspartner verstanden sie als <button type="button" class="article-term" data-term-id="term-19">Zweifel</button> am Recht Israels, als Staat zu <button type="button" class="article-term" data-term-id="term-20">bestehen</button>. Außerdem <button type="button" class="article-term" data-term-id="term-21">unterstützte</button> Emde den Aktivisten Ibrahim Ibrahim. <button type="button" class="article-term" data-term-id="term-22">Sicherheitsbehörden</button> sehen ihn als der Hamas <button type="button" class="article-term article-term--default" data-term-id="term-23">nahestehend</button>. Die Hamas ist eine islamistische Organisation, die Israel <button type="button" class="article-term" data-term-id="term-24">angreift</button>. Besonders <button type="button" class="article-term" data-term-id="term-25">heikel</button> wurde der Fall nach einer <button type="button" class="article-term" data-term-id="term-26">Erklärung</button> gegen <button type="button" class="article-term article-term--default" data-term-id="term-27">Judenfeindlichkeit</button>. Emde hatte diese <button type="button" class="article-term" data-term-id="term-26">Erklärung</button> <button type="button" class="article-term" data-term-id="term-28">mitgetragen</button>. <button type="button" class="article-term" data-term-id="term-29">Kurz danach</button> <button type="button" class="article-term" data-term-id="term-30">veröffentlichte</button> sie ein Video. Kritiker sahen darin einen <button type="button" class="article-term" data-term-id="term-31">Widerspruch</button> zur <button type="button" class="article-term" data-term-id="term-26">Erklärung</button>. Auch ihr Protest gegen die eigene <button type="button" class="article-term" data-term-id="term-32">Parteiführung</button> bei einem Linke-Parteitag <button type="button" class="article-term" data-term-id="term-33">verschärfte</button> den <button type="button" class="article-term" data-term-id="term-2">Streit</button>.

<button type="button" class="article-term" data-term-id="term-34">Folgen</button> für <button type="button" class="article-term" data-term-id="term-37">Gespräche</button>
Die Affäre <button type="button" class="article-term" data-term-id="term-35">belastete</button> <button type="button" class="article-term" data-term-id="term-36">zeitweise</button> <button type="button" class="article-term" data-term-id="term-37">Gespräche</button> mit Grünen und SPD über eine mögliche Regierung. Solche ersten <button type="button" class="article-term" data-term-id="term-37">Gespräche</button> heißen <button type="button" class="article-term article-term--default" data-term-id="term-38">Sondierungen</button>. <button type="button" class="article-term" data-term-id="term-39">Vertreter</button> beider Parteien <button type="button" class="article-term" data-term-id="term-40">verlangten</button> klare <button type="button" class="article-term" data-term-id="term-34">Folgen</button> im Fall Emde. Deshalb <button type="button" class="article-term" data-term-id="term-41">pausierten</button> die <button type="button" class="article-term" data-term-id="term-37">Gespräche</button> kurz. Später schlossen die Parteien sie aber ab. In der Linken gilt Emde auch als <button type="button" class="article-term" data-term-id="term-42">Gegnerin</button> einer <button type="button" class="article-term" data-term-id="term-43">Regierungsbeteiligung</button>. Für weiteren <button type="button" class="article-term" data-term-id="term-44">Ärger</button> sorgte ihre <button type="button" class="article-term" data-term-id="term-45">Einladung</button> der antiisraelischen Aktivistin Hannah Bruns zu einer <button type="button" class="article-term" data-term-id="term-46">Fraktionssitzung</button>. Gegen Bruns läuft bereits ein <button type="button" class="article-term" data-term-id="term-47">Antrag</button> auf <button type="button" class="article-term article-term--default" data-term-id="term-48">Parteiausschluss</button>.

<button type="button" class="article-term" data-term-id="term-49">Wie es weitergeht</button>
Ob Emde ihr <button type="button" class="article-term" data-term-id="term-1">Mandat</button> abgibt, ist <button type="button" class="article-term" data-term-id="term-50">offen</button>. In der Partei <button type="button" class="article-term" data-term-id="term-51">rechnen</button> viele nicht damit. Sie sagte zuletzt: Sie nimmt keine ihrer <button type="button" class="article-term" data-term-id="term-52">umstrittenen</button> <button type="button" class="article-term" data-term-id="term-18">Aussagen</button> zurück. Behält sie den <button type="button" class="article-term" data-term-id="term-6">Sitz</button>, kann die <button type="button" class="article-term" data-term-id="term-53">Fraktionsführung</button> ihren <button type="button" class="article-term" data-term-id="term-54">Ausschluss</button> aus der Linksfraktion <button type="button" class="article-term" data-term-id="term-55">beantragen</button>. Dafür braucht sie <button type="button" class="article-term" data-term-id="term-56">zwei Drittel</button> der Stimmen. Diese <button type="button" class="article-term" data-term-id="term-57">Mehrheit</button> gilt inzwischen als möglich. Katalin Gennburg und Gregor Gysi fordern eine <button type="button" class="article-term" data-term-id="term-58">Trennung</button>. Unterstützer Emdes sehen dagegen ein <button type="button" class="article-term" data-term-id="term-59">Nachgeben</button> vor <button type="button" class="article-term" data-term-id="term-60">öffentlichem Druck</button>. Sie werfen der <button type="button" class="article-term" data-term-id="term-32">Parteiführung</button> vor, für eine mögliche Koalition eigene <button type="button" class="article-term" data-term-id="term-61">Grundsätze</button> <button type="button" class="article-term" data-term-id="term-62">aufzugeben</button>.
