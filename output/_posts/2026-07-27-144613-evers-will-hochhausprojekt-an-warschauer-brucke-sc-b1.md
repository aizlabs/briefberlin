Der <button type="button" class="article-term" data-term-id="term-2">Streit</button> um ein <button type="button" class="article-term" data-term-id="term-3">geplantes</button> Hochhaus in Berlin-Friedrichshain wird kurz vor der <button type="button" class="article-term" data-term-id="term-4">Wahl</button> zum Abgeordnetenhaus <button type="button" class="article-term" data-term-id="term-5">schärfer</button>. Das Abgeordnetenhaus ist das Berliner <button type="button" class="article-term" data-term-id="term-1">Landesparlament</button>. <button type="button" class="article-term" data-term-id="term-6">Auslöser</button> ist ein neuer <button type="button" class="article-term" data-term-id="term-7">Vorschlag</button> von Evers, der das Projekt an der Rudolfstraße <button type="button" class="article-term article-term--default" data-term-id="term-8">voranbringen</button> will. Dort, <button type="button" class="article-term" data-term-id="term-9">nahe</button> der Warschauer Brücke, soll ein großes <button type="button" class="article-term" data-term-id="term-10">Wohnprojekt</button> mit etwa 1000 Wohnungen <button type="button" class="article-term" data-term-id="term-11">entstehen</button>.

Der Berliner Senat möchte dafür <button type="button" class="article-term" data-term-id="term-12">möglichst schnell</button> <button type="button" class="article-term article-term--default" data-term-id="term-13">Baurecht</button> <button type="button" class="article-term" data-term-id="term-14">schaffen</button>. Das bedeutet: Die Stadt soll <button type="button" class="article-term" data-term-id="term-15">rechtlich festlegen</button>, dass auf dem <button type="button" class="article-term article-term--default" data-term-id="term-16">Grundstück</button> <button type="button" class="article-term" data-term-id="term-17">gebaut werden darf</button>. Für die <button type="button" class="article-term article-term--default" data-term-id="term-18">Befürworter</button> ist das wichtig, weil Berlin <button type="button" class="article-term" data-term-id="term-19">dringend</button> mehr Wohnungen braucht. Außerdem könnte das Projekt vielen Menschen eine Wohnung in <button type="button" class="article-term" data-term-id="term-20">zentraler Lage</button> <button type="button" class="article-term" data-term-id="term-21">bieten</button>.

Kritiker sehen die Pläne <button type="button" class="article-term" data-term-id="term-22">jedoch</button> <button type="button" class="article-term" data-term-id="term-23">mit Sorge</button>. Sie haben schon vorher auf Probleme im <button type="button" class="article-term" data-term-id="term-24">Umfeld</button> <button type="button" class="article-term" data-term-id="term-25">hingewiesen</button>. Besonders die Warschauer Brücke ist ein wichtiger <button type="button" class="article-term article-term--default" data-term-id="term-26">Verkehrsknoten</button> im Osten Berlins. Dort treffen viele <button type="button" class="article-term" data-term-id="term-27">Verkehrsmittel</button>, Autos, Fahrräder und <button type="button" class="article-term" data-term-id="term-28">Fußgänger</button> <button type="button" class="article-term" data-term-id="term-29">aufeinander</button>. Zu <button type="button" class="article-term article-term--default" data-term-id="term-30">Stoßzeiten</button>, also morgens und am späten Nachmittag, ist der <button type="button" class="article-term" data-term-id="term-31">Bereich</button> <button type="button" class="article-term" data-term-id="term-32">bereits</button> <button type="button" class="article-term" data-term-id="term-33">stark belastet</button>.

Außerdem geht es um die soziale Infrastruktur im <button type="button" class="article-term" data-term-id="term-34">Viertel</button>. Damit meinen die Kritiker <button type="button" class="article-term" data-term-id="term-35">Angebote</button>, die Menschen im <button type="button" class="article-term" data-term-id="term-36">Alltag</button> brauchen. <button type="button" class="article-term" data-term-id="term-37">Dazu gehören</button> zum Beispiel Spielplätze, <button type="button" class="article-term" data-term-id="term-38">Kitas</button>, Schulen und andere Orte für Familien. Wenn dort <button type="button" class="article-term" data-term-id="term-39">rund</button> 1000 neue Wohnungen <button type="button" class="article-term" data-term-id="term-11">entstehen</button>, werden auch mehr Menschen diese <button type="button" class="article-term" data-term-id="term-35">Angebote</button> <button type="button" class="article-term" data-term-id="term-40">nutzen</button>.

Deshalb ist der <button type="button" class="article-term" data-term-id="term-2">Streit</button> mehr als eine Frage der <button type="button" class="article-term" data-term-id="term-41">Höhe</button> des Gebäudes. Es geht auch darum, wie schnell Berlin <button type="button" class="article-term" data-term-id="term-42">wachsen</button> kann. Gleichzeitig <button type="button" class="article-term" data-term-id="term-43">stellt sich</button> die Frage, welche <button type="button" class="article-term" data-term-id="term-44">Folgen</button> das für die <button type="button" class="article-term" data-term-id="term-45">Umgebung</button> hat. <button type="button" class="article-term" data-term-id="term-46">Während</button> der Senat <button type="button" class="article-term article-term--default" data-term-id="term-47">Tempo machen</button> will, <button type="button" class="article-term" data-term-id="term-48">verlangen</button> Gegner genauere <button type="button" class="article-term" data-term-id="term-49">Prüfungen</button>. Kurz vor der <button type="button" class="article-term" data-term-id="term-4">Wahl</button> bekommt das Thema <button type="button" class="article-term" data-term-id="term-50">dadurch</button> <button type="button" class="article-term" data-term-id="term-51">zusätzliche</button> politische <button type="button" class="article-term" data-term-id="term-52">Bedeutung</button>.
