Die Kalle Halle in Berlin-Neukölln hat große Probleme. Sie <button type="button" class="article-term" data-term-id="term-1">öffnete</button> <button type="button" class="article-term" data-term-id="term-2">erst</button> vor zehn Monaten in der Karl-Marx-Straße. Anfang Juli meldete die <button type="button" class="article-term article-term--default" data-term-id="term-3">Betreiberfirma</button> dort <button type="button" class="article-term article-term--default" data-term-id="term-4">Insolvenz an</button>. <button type="button" class="article-term" data-term-id="term-5">Das heißt</button>: Die Firma kann ihre <button type="button" class="article-term" data-term-id="term-6">Rechnungen</button> nicht mehr normal bezahlen.

Die <button type="button" class="article-term article-term--default" data-term-id="term-7">Eigentümerfirma</button> K101 hat vorher den <button type="button" class="article-term article-term--default" data-term-id="term-8">Mietvertrag</button> <button type="button" class="article-term" data-term-id="term-9">gekündigt</button>. Sie sagt: <button type="button" class="article-term" data-term-id="term-10">Seit</button> der <button type="button" class="article-term" data-term-id="term-11">Eröffnung</button> hat sie keine <button type="button" class="article-term" data-term-id="term-12">Miete</button> bekommen. Die <button type="button" class="article-term article-term--default" data-term-id="term-3">Betreiberfirma</button> hat aber Geld von den Restaurants und Cafés <button type="button" class="article-term" data-term-id="term-13">erhalten</button>. <button type="button" class="article-term" data-term-id="term-14">Darum</button> gibt es jetzt <button type="button" class="article-term" data-term-id="term-15">Streit</button> um <button type="button" class="article-term article-term--default" data-term-id="term-16">offene Rechnungen</button>.

Der <button type="button" class="article-term" data-term-id="term-17">Betreiber</button> Martin Barry sieht die <button type="button" class="article-term" data-term-id="term-18">Sache</button> <button type="button" class="article-term" data-term-id="term-19">anders</button>. Er sagt: Seine Firma hat <button type="button" class="article-term article-term--default" data-term-id="term-20">mit Hilfe</button> beim Start <button type="button" class="article-term" data-term-id="term-21">gerechnet</button>. Auch <button type="button" class="article-term" data-term-id="term-22">Änderungen</button> bei den <button type="button" class="article-term" data-term-id="term-23">Kosten</button> waren für ihn wichtig. Die <button type="button" class="article-term article-term--default" data-term-id="term-7">Eigentümerfirma</button> sagt aber: <button type="button" class="article-term" data-term-id="term-24">Solche</button> <button type="button" class="article-term" data-term-id="term-25">Absprachen</button> gab es nicht. Sie nennt nur <button type="button" class="article-term" data-term-id="term-26">geliehenes</button> Geld für den <button type="button" class="article-term" data-term-id="term-27">Bau</button> der <button type="button" class="article-term article-term--default" data-term-id="term-28">Essensstände</button>.

Auch das <button type="button" class="article-term" data-term-id="term-29">Geschäft</button> in der Halle ist <button type="button" class="article-term" data-term-id="term-30">schwierig</button>. Barry sagt: Es kommen <button type="button" class="article-term" data-term-id="term-31">zurzeit</button> <button type="button" class="article-term" data-term-id="term-32">zu wenige</button> <button type="button" class="article-term" data-term-id="term-33">Gäste</button>. Viele Menschen geben weniger Geld für Essen aus. Auch <button type="button" class="article-term" data-term-id="term-34">Büros</button> und eine <button type="button" class="article-term" data-term-id="term-35">Hochschule</button> im Haus <button type="button" class="article-term" data-term-id="term-36">bringen</button> noch nicht <button type="button" class="article-term" data-term-id="term-37">genug</button> <button type="button" class="article-term" data-term-id="term-38">Besucher</button>. Die <button type="button" class="article-term article-term--default" data-term-id="term-7">Eigentümerfirma</button> sagt <button type="button" class="article-term" data-term-id="term-39">trotzdem</button>: Das ganze Kalle-Neukölln-Haus <button type="button" class="article-term" data-term-id="term-40">läuft</button> gut. Dort gibt es <button type="button" class="article-term" data-term-id="term-41">Geschäfte</button>, <button type="button" class="article-term" data-term-id="term-42">Firmen</button>, <button type="button" class="article-term" data-term-id="term-43">Bildung</button> und <button type="button" class="article-term" data-term-id="term-44">weitere</button> Restaurants.

Für die zwölf Restaurants und Cafés ist jetzt <button type="button" class="article-term article-term--default" data-term-id="term-45">Sicherheit</button> wichtig. Sie sollen <button type="button" class="article-term" data-term-id="term-46">zuerst</button> <button type="button" class="article-term" data-term-id="term-47">ohne</button> die alte <button type="button" class="article-term article-term--default" data-term-id="term-3">Betreiberfirma</button> <button type="button" class="article-term" data-term-id="term-48">weiterarbeiten</button>. <button type="button" class="article-term" data-term-id="term-49">Danach</button> sollen sie ihre <button type="button" class="article-term" data-term-id="term-50">Flächen</button> <button type="button" class="article-term" data-term-id="term-51">direkt</button> von K101 <button type="button" class="article-term" data-term-id="term-52">mieten</button>. Ein <button type="button" class="article-term" data-term-id="term-53">Gericht</button> und <button type="button" class="article-term" data-term-id="term-54">Fachleute</button> <button type="button" class="article-term" data-term-id="term-55">klären</button> <button type="button" class="article-term" data-term-id="term-56">später</button> die offenen <button type="button" class="article-term" data-term-id="term-57">Geldfragen</button>. <button type="button" class="article-term" data-term-id="term-58">Am Ende</button> <button type="button" class="article-term" data-term-id="term-59">wird klar</button>: Die <button type="button" class="article-term" data-term-id="term-60">Markthalle</button> hat eine <button type="button" class="article-term" data-term-id="term-61">Zukunft</button> oder nicht.
