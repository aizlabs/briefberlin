Auf dem RAW-<button type="button" class="article-term article-term--default" data-term-id="term-2">Gelände</button> in Berlin-Friedrichshain gibt es neue <button type="button" class="article-term" data-term-id="term-1">Pläne</button>. Das Land Berlin, der Bezirk Friedrichshain-Kreuzberg und die Kurth-Gruppe <button type="button" class="article-term article-term--default" data-term-id="term-3">haben sich geeinigt</button>. Die Kurth-Gruppe <button type="button" class="article-term" data-term-id="term-4">besitzt</button> das <button type="button" class="article-term article-term--default" data-term-id="term-2">Gelände</button>. Die <button type="button" class="article-term" data-term-id="term-1">Pläne</button> <button type="button" class="article-term" data-term-id="term-5">sichern</button> Clubs und <button type="button" class="article-term article-term--default" data-term-id="term-6">Kulturorte</button> <button type="button" class="article-term" data-term-id="term-7">zuerst</button> für drei Jahre.

Das <button type="button" class="article-term article-term--default" data-term-id="term-2">Gelände</button> <button type="button" class="article-term" data-term-id="term-8">liegt</button> <button type="button" class="article-term" data-term-id="term-9">nahe</button> der Warschauer Brücke. Dort gibt es Clubs, eine <button type="button" class="article-term" data-term-id="term-10">Skatehalle</button> und andere <button type="button" class="article-term" data-term-id="term-11">Kulturangebote</button>. Auch der Sommergarten <button type="button" class="article-term" data-term-id="term-12">gehört dazu</button>. <button type="button" class="article-term" data-term-id="term-13">Spätestens</button> in drei Jahren soll ein <button type="button" class="article-term article-term--default" data-term-id="term-14">Bauplan</button> kommen. Dieser Plan sagt, wo neue Häuser <button type="button" class="article-term" data-term-id="term-15">stehen dürfen</button>.

Die Kurth-Gruppe <button type="button" class="article-term" data-term-id="term-16">darf</button> auch <button type="button" class="article-term" data-term-id="term-17">Wohnungen</button> planen. <button type="button" class="article-term" data-term-id="term-18">Insgesamt</button> sollen 300 <button type="button" class="article-term article-term--default" data-term-id="term-19">Mietwohnungen</button> <button type="button" class="article-term" data-term-id="term-20">entstehen</button>. Ein <button type="button" class="article-term" data-term-id="term-21">Teil</button> davon soll <button type="button" class="article-term" data-term-id="term-22">günstiger</button> sein, <button type="button" class="article-term" data-term-id="term-23">weil</button> die Stadt <button type="button" class="article-term" data-term-id="term-24">hilft</button>. <button type="button" class="article-term" data-term-id="term-25">Außerdem</button> sollen neue <button type="button" class="article-term" data-term-id="term-26">Räume</button> für <button type="button" class="article-term" data-term-id="term-27">Firmen</button> <button type="button" class="article-term" data-term-id="term-20">entstehen</button>. Ein Haus <button type="button" class="article-term" data-term-id="term-16">darf</button> <button type="button" class="article-term" data-term-id="term-28">bis zu</button> 100 Meter hoch sein.

In der <button type="button" class="article-term article-term--default" data-term-id="term-29">Übergangszeit</button> <button type="button" class="article-term" data-term-id="term-30">steigt</button> die <button type="button" class="article-term article-term--default" data-term-id="term-31">Miete</button> für die <button type="button" class="article-term article-term--default" data-term-id="term-6">Kulturorte</button>. Sie soll 11,20 Euro pro Quadratmeter kosten. Die <button type="button" class="article-term article-term--default" data-term-id="term-6">Kulturorte</button> <button type="button" class="article-term" data-term-id="term-32">zahlen</button> aber nicht alles <button type="button" class="article-term" data-term-id="term-33">selbst</button>. <button type="button" class="article-term" data-term-id="term-7">Zuerst</button> <button type="button" class="article-term" data-term-id="term-24">hilft</button> der Bezirk mit Geld. <button type="button" class="article-term" data-term-id="term-34">Danach</button> <button type="button" class="article-term" data-term-id="term-24">hilft</button> die Berliner <button type="button" class="article-term" data-term-id="term-35">Stadtregierung</button>, wenn der <button type="button" class="article-term article-term--default" data-term-id="term-14">Bauplan</button> <button type="button" class="article-term" data-term-id="term-47">noch</button> <button type="button" class="article-term" data-term-id="term-36">fehlt</button>. <button type="button" class="article-term" data-term-id="term-37">Es geht um</button> <button type="button" class="article-term" data-term-id="term-38">etwa</button> eine Million Euro <button type="button" class="article-term" data-term-id="term-39">pro Jahr</button>. Ein <button type="button" class="article-term" data-term-id="term-21">Teil</button> des Geldes ist für alte <button type="button" class="article-term" data-term-id="term-40">Gebäude</button> und wichtige Reparaturen.

Wenn der <button type="button" class="article-term article-term--default" data-term-id="term-14">Bauplan</button> <button type="button" class="article-term" data-term-id="term-41">fertig</button> ist, soll ein <button type="button" class="article-term" data-term-id="term-42">Vertrag</button> 30 Jahre <button type="button" class="article-term" data-term-id="term-43">gelten</button>. Eine Organisation soll dann die <button type="button" class="article-term article-term--default" data-term-id="term-6">Kulturorte</button> <button type="button" class="article-term" data-term-id="term-44">verwalten</button>. Sie zahlt keine <button type="button" class="article-term" data-term-id="term-45">feste Miete</button>, aber sie <button type="button" class="article-term" data-term-id="term-46">pflegt</button> die <button type="button" class="article-term" data-term-id="term-40">Gebäude</button>. <button type="button" class="article-term" data-term-id="term-47">Noch</button> müssen das <button type="button" class="article-term" data-term-id="term-48">Bezirksparlament</button> und eine Gruppe im Berliner Parlament <button type="button" class="article-term" data-term-id="term-49">zustimmen</button>. <button type="button" class="article-term" data-term-id="term-25">Außerdem</button> <button type="button" class="article-term" data-term-id="term-50">brauchen</button> die <button type="button" class="article-term" data-term-id="term-17">Wohnungen</button> <button type="button" class="article-term" data-term-id="term-51">Schutz</button> vor <button type="button" class="article-term" data-term-id="term-52">Lärm</button>.
