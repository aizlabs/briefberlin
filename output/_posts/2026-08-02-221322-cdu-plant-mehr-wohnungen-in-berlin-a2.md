Die Berliner CDU, eine Partei in Deutschland, will mehr Wohnungen <button type="button" class="article-term article-term--default" data-term-id="term-1">schaffen</button>. Stefan Evers ist ihr Kandidat für das <button type="button" class="article-term" data-term-id="term-2">Amt</button> des <button type="button" class="article-term" data-term-id="term-3">Bürgermeisters</button>. Die Pläne <button type="button" class="article-term" data-term-id="term-4">betreffen</button> Büros, <button type="button" class="article-term" data-term-id="term-5">Dächer</button> und das Tempelhofer Feld.

<button type="button" class="article-term" data-term-id="term-6">Zuerst</button> will Evers <button type="button" class="article-term" data-term-id="term-7">leere</button> Büros besser <button type="button" class="article-term" data-term-id="term-8">nutzen</button>. Manche Büros und <button type="button" class="article-term article-term--default" data-term-id="term-9">Firmenhäuser</button> <button type="button" class="article-term" data-term-id="term-10">stehen leer</button> oder haben viel Platz. <button type="button" class="article-term article-term--default" data-term-id="term-11">Eigentümer</button> können sie für eine Zeit zu Wohnungen <button type="button" class="article-term article-term--default" data-term-id="term-12">umbauen</button>. Eine neue <button type="button" class="article-term" data-term-id="term-13">Stelle</button> soll Eigentümern helfen und die Arbeit planen.

<button type="button" class="article-term" data-term-id="term-31">Dann</button> will die CDU Häuser <button type="button" class="article-term" data-term-id="term-14">höher</button> machen. Auf manchen Dächern können neue <button type="button" class="article-term article-term--default" data-term-id="term-15">Stockwerke</button> <button type="button" class="article-term" data-term-id="term-16">entstehen</button>. So braucht Berlin weniger neue <button type="button" class="article-term" data-term-id="term-17">Flächen</button> am <button type="button" class="article-term article-term--default" data-term-id="term-18">Stadtrand</button>. Aber das ist oft schwer. Häuser müssen <button type="button" class="article-term" data-term-id="term-19">sicher</button> sein, und der <button type="button" class="article-term article-term--default" data-term-id="term-20">Brandschutz</button> <button type="button" class="article-term" data-term-id="term-21">muss stimmen</button>. <button type="button" class="article-term" data-term-id="term-22">Außerdem</button> müssen <button type="button" class="article-term article-term--default" data-term-id="term-11">Eigentümer</button> <button type="button" class="article-term" data-term-id="term-23">zustimmen</button>.

Evers sagt auch etwas zu großen <button type="button" class="article-term" data-term-id="term-24">Wohnungsfirmen</button>. Der Staat soll <button type="button" class="article-term" data-term-id="term-25">solche</button> Firmen nicht <button type="button" class="article-term" data-term-id="term-26">übernehmen</button>. Bei einer <button type="button" class="article-term" data-term-id="term-27">Abstimmung</button> haben viele Berliner <button type="button" class="article-term" data-term-id="term-28">dafür gestimmt</button>. Die CDU <button type="button" class="article-term" data-term-id="term-30">lehnt</button> diesen Plan aber <button type="button" class="article-term" data-term-id="term-29">weiter</button> ab. Evers sagt: Firmen bauen <button type="button" class="article-term" data-term-id="term-31">dann</button> weniger neue Wohnungen. Andere Menschen sagen: Große Firmen machen <button type="button" class="article-term" data-term-id="term-32">Mieten</button> <button type="button" class="article-term" data-term-id="term-33">teurer</button>.

Ein großer <button type="button" class="article-term article-term--default" data-term-id="term-34">Streitpunkt</button> ist das Tempelhofer Feld. Das ist ein großes freies <button type="button" class="article-term" data-term-id="term-35">Gelände</button> von einem <button type="button" class="article-term" data-term-id="term-36">alten</button> <button type="button" class="article-term" data-term-id="term-37">Flughafen</button>. Die CDU möchte <button type="button" class="article-term" data-term-id="term-38">am Rand</button> Wohnungen bauen. Evers spricht von <button type="button" class="article-term" data-term-id="term-39">bezahlbarem Wohnraum</button> für <button type="button" class="article-term" data-term-id="term-40">bis zu</button> 50.000 Menschen. Aber 2014 <button type="button" class="article-term" data-term-id="term-41">stimmten</button> viele Berliner <button type="button" class="article-term" data-term-id="term-42">gegen</button> Bauen auf diesem <button type="button" class="article-term" data-term-id="term-35">Gelände</button>. <button type="button" class="article-term" data-term-id="term-43">Deshalb</button> <button type="button" class="article-term" data-term-id="term-44">bleibt</button> die Frage schwer: Wo soll Berlin neue Wohnungen bauen?
