Steglitz-Zehlendorf will leere Geschäfte im <button type="button" class="article-term article-term--default" data-term-id="term-1">Bezirk</button> besser <button type="button" class="article-term" data-term-id="term-2">erfassen</button>. <button type="button" class="article-term" data-term-id="term-3">Dafür</button> plant der Berliner <button type="button" class="article-term article-term--default" data-term-id="term-1">Bezirk</button> einen digitalen Leerstandsmelder für <button type="button" class="article-term article-term--default" data-term-id="term-4">Gewerberäume</button>, also für Läden, Büros und andere <button type="button" class="article-term" data-term-id="term-5">Geschäftsräume</button>. Die <button type="button" class="article-term article-term--default" data-term-id="term-6">Bezirksverordnetenversammlung</button> hat <button type="button" class="article-term" data-term-id="term-3">dafür</button> einen <button type="button" class="article-term article-term--default" data-term-id="term-7">Prüfauftrag</button> <button type="button" class="article-term" data-term-id="term-8">beschlossen</button>. Dieses <button type="button" class="article-term" data-term-id="term-9">gewählte</button> <button type="button" class="article-term" data-term-id="term-10">Bezirksparlament</button> soll nun <button type="button" class="article-term" data-term-id="term-11">klären lassen</button>, wie so ein Online-Angebot funktionieren kann.

Mit dem neuen Instrument möchte der <button type="button" class="article-term article-term--default" data-term-id="term-1">Bezirk</button> schneller sehen, wo Räume <button type="button" class="article-term article-term--default" data-term-id="term-12">frei stehen</button>. <button type="button" class="article-term" data-term-id="term-13">Gleichzeitig</button> sollen <button type="button" class="article-term" data-term-id="term-14">mögliche</button> neue <button type="button" class="article-term" data-term-id="term-15">Nutzer</button> <button type="button" class="article-term" data-term-id="term-16">leichter</button> Kontakt zu den <button type="button" class="article-term article-term--default" data-term-id="term-17">Eigentümern</button> bekommen. Das können zum Beispiel <button type="button" class="article-term" data-term-id="term-18">Händler</button>, <button type="button" class="article-term" data-term-id="term-19">Dienstleister</button> oder kleine Firmen sein. Wenn ein Laden lange <button type="button" class="article-term" data-term-id="term-20">leer bleibt</button>, <button type="button" class="article-term" data-term-id="term-21">wirkt</button> eine <button type="button" class="article-term article-term--default" data-term-id="term-22">Einkaufsstraße</button> oft weniger <button type="button" class="article-term" data-term-id="term-23">lebendig</button>. <button type="button" class="article-term" data-term-id="term-24">Deshalb</button> will der <button type="button" class="article-term article-term--default" data-term-id="term-1">Bezirk</button> solche <button type="button" class="article-term" data-term-id="term-25">Orte</button> früher <button type="button" class="article-term" data-term-id="term-26">sichtbar machen</button>.

Andere Städte in Deutschland nutzen <button type="button" class="article-term" data-term-id="term-27">ähnliche</button> Angebote <button type="button" class="article-term" data-term-id="term-28">bereits</button>. München, Nürnberg, Saarbrücken und Goslar haben Online-Seiten für freie <button type="button" class="article-term article-term--default" data-term-id="term-4">Gewerberäume</button> <button type="button" class="article-term" data-term-id="term-29">eingerichtet</button>. Einige zeigen die Räume auf digitalen Karten. Andere helfen dabei, <button type="button" class="article-term" data-term-id="term-30">passende</button> Kontakte zu finden. Steglitz-Zehlendorf sieht diese Städte als <button type="button" class="article-term" data-term-id="term-31">Vorbilder</button>, weil sie <button type="button" class="article-term" data-term-id="term-32">Erfahrungen</button> mit solchen Lösungen <button type="button" class="article-term" data-term-id="term-33">gesammelt</button> haben.

Im Berliner Südwesten soll der Leerstandsmelder <button type="button" class="article-term" data-term-id="term-34">besonders</button> <button type="button" class="article-term article-term--default" data-term-id="term-35">verwaiste</button> <button type="button" class="article-term" data-term-id="term-36">Ladenlokale</button> und <button type="button" class="article-term" data-term-id="term-37">Büroflächen</button> zeigen. Verwaist <button type="button" class="article-term" data-term-id="term-38">bedeutet</button> hier, dass Räume nicht <button type="button" class="article-term" data-term-id="term-39">genutzt</button> werden und leer bleiben. So könnten <button type="button" class="article-term" data-term-id="term-40">Interessenten</button> schneller <button type="button" class="article-term" data-term-id="term-41">erkennen</button>, welche <button type="button" class="article-term" data-term-id="term-42">Flächen</button> es in einer Straße gibt. <button type="button" class="article-term" data-term-id="term-43">Außerdem</button> bekommen Eigentümer eine bessere Möglichkeit, ihre Räume <button type="button" class="article-term" data-term-id="term-44">anzubieten</button>.

Noch ist der digitale Melder nicht gestartet. <button type="button" class="article-term" data-term-id="term-45">Zuerst</button> <button type="button" class="article-term" data-term-id="term-46">prüft</button> der <button type="button" class="article-term article-term--default" data-term-id="term-1">Bezirk</button>, welche Daten <button type="button" class="article-term" data-term-id="term-47">nötig</button> sind und wer sie <button type="button" class="article-term" data-term-id="term-48">pflegen</button> kann. Auch Fragen zum <button type="button" class="article-term" data-term-id="term-49">Datenschutz</button> und zur <button type="button" class="article-term" data-term-id="term-50">Zusammenarbeit</button> mit <button type="button" class="article-term article-term--default" data-term-id="term-17">Eigentümern</button> <button type="button" class="article-term" data-term-id="term-51">müssen geklärt werden</button>. <button type="button" class="article-term" data-term-id="term-52">Trotzdem</button> ist das Ziel schon klar: Die <button type="button" class="article-term" data-term-id="term-53">Geschäftsstraßen</button> sollen attraktiver werden. Mehr genutzte Räume können Kunden <button type="button" class="article-term" data-term-id="term-54">anziehen</button> und das Leben im <button type="button" class="article-term" data-term-id="term-55">Kiez</button> <button type="button" class="article-term" data-term-id="term-56">stärken</button>.
