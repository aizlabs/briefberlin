Am Samstag hat in Berlin die vierte <button type="button" class="article-term" data-term-id="term-2">Weltmeisterschaft</button> in „Mensch ärgere dich nicht“ <button type="button" class="article-term article-term--default" data-term-id="term-3">stattgefunden</button>. Das ist ein <button type="button" class="article-term" data-term-id="term-4">bekanntes</button> <button type="button" class="article-term article-term--default" data-term-id="term-5">Brettspiel</button> mit <button type="button" class="article-term article-term--default" data-term-id="term-6">Würfeln</button>. Mandy Kunze aus Sachsen hat wieder <button type="button" class="article-term" data-term-id="term-7">gewonnen</button>.

172 Menschen haben in einem Hotel an 43 <button type="button" class="article-term" data-term-id="term-8">Tischen</button> gespielt. <button type="button" class="article-term" data-term-id="term-9">Die meisten</button> kommen aus Deutschland. <button type="button" class="article-term" data-term-id="term-10">Einige</button> kommen auch aus den Niederlanden, aus Österreich und aus der Schweiz. Die <button type="button" class="article-term" data-term-id="term-11">jüngste</button> Spielerin war sieben Jahre alt. Die <button type="button" class="article-term" data-term-id="term-12">älteste</button> Person war <button type="button" class="article-term" data-term-id="term-13">fast</button> 90 Jahre alt.

Die <button type="button" class="article-term" data-term-id="term-14">Firma</button> Schmidt Spiele hat das <button type="button" class="article-term article-term--default" data-term-id="term-15">Turnier</button> organisiert. Sie macht das Spiel seit 1915. Die <button type="button" class="article-term" data-term-id="term-14">Firma</button> hat es schon <button type="button" class="article-term" data-term-id="term-17">etwa</button> 100 Millionen Mal <button type="button" class="article-term" data-term-id="term-16">verkauft</button>. Heute kaufen es jedes Jahr <button type="button" class="article-term" data-term-id="term-17">etwa</button> 400.000 Menschen. Auch viele <button type="button" class="article-term" data-term-id="term-18">Jugendliche</button> <button type="button" class="article-term" data-term-id="term-19">mögen</button> das Spiel. Sie wollen eine Pause vom Handy und vom Computer.

<button type="button" class="article-term" data-term-id="term-20">Zuerst</button> hat es vier <button type="button" class="article-term" data-term-id="term-21">Runden</button> gegeben. Dort haben die Spieler Punkte <button type="button" class="article-term" data-term-id="term-22">gesammelt</button>. <button type="button" class="article-term" data-term-id="term-23">Danach</button> haben <button type="button" class="article-term" data-term-id="term-24">die vier Besten</button> das Finale gespielt. Das Team von der <button type="button" class="article-term" data-term-id="term-14">Firma</button> sagt: Taktik ist <button type="button" class="article-term" data-term-id="term-25">wichtig</button>. Aber man kann das Spiel nicht trainieren. Für die <button type="button" class="article-term" data-term-id="term-14">Firma</button> ist das Spiel auch ein Spiel <button type="button" class="article-term" data-term-id="term-26">zum Reden</button>.

Christel Haase ist 77 Jahre alt und kommt aus Potsdam. Sie sagt: „Ich muss nicht gewinnen. Aber das Spiel hält meinen Kopf fit.“

Mandy Kunze ist 50 Jahre alt. Sie war schon vor zwei Jahren <button type="button" class="article-term article-term--default" data-term-id="term-1">Weltmeisterin</button>. Ihre Taktik ist <button type="button" class="article-term" data-term-id="term-27">einfach</button>. Sie zieht mit einer <button type="button" class="article-term" data-term-id="term-29">Figur</button> <button type="button" class="article-term" data-term-id="term-28">still</button> an den anderen vorbei. Nach <button type="button" class="article-term" data-term-id="term-17">etwa</button> 30 Minuten hatte sie alle vier Figuren <button type="button" class="article-term" data-term-id="term-30">im Ziel</button>. Die anderen hatten <button type="button" class="article-term" data-term-id="term-31">erst</button> ein oder zwei Figuren <button type="button" class="article-term" data-term-id="term-30">im Ziel</button>. Kunze hat einen <button type="button" class="article-term article-term--default" data-term-id="term-32">Pokal</button> bekommen. <button type="button" class="article-term" data-term-id="term-33">Außerdem</button> hat sie einen <button type="button" class="article-term article-term--default" data-term-id="term-34">Gutschein</button> für eine <button type="button" class="article-term" data-term-id="term-35">Reise</button> bekommen. Er ist 250 Euro <button type="button" class="article-term" data-term-id="term-36">wert</button>.
