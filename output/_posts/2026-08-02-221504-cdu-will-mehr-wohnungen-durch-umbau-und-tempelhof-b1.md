Die Berliner CDU will den <button type="button" class="article-term article-term--default" data-term-id="term-1">Wohnungsmangel</button> mit neuen Ideen <button type="button" class="article-term" data-term-id="term-2">bekämpfen</button>. <button type="button" class="article-term" data-term-id="term-3">Bürgermeisterkandidat</button> Stefan Evers stellte dafür <button type="button" class="article-term" data-term-id="term-4">vor allem</button> zwei Wege <button type="button" class="article-term" data-term-id="term-5">in den Mittelpunkt</button>. Leere Büros und <button type="button" class="article-term article-term--default" data-term-id="term-6">Gewerbeflächen</button> sollen schneller zu Wohnungen werden. <button type="button" class="article-term" data-term-id="term-7">Außerdem</button> will die Partei <button type="button" class="article-term" data-term-id="term-8">bestehende</button> Häuser um weitere <button type="button" class="article-term" data-term-id="term-9">Etagen</button> <button type="button" class="article-term" data-term-id="term-10">erhöhen</button>.

Für solche <button type="button" class="article-term" data-term-id="term-11">Umbauten</button> plant die CDU eine besondere <button type="button" class="article-term" data-term-id="term-12">Stelle</button>. Diese <button type="button" class="article-term article-term--default" data-term-id="term-13">Umbauagentur</button> soll <button type="button" class="article-term article-term--default" data-term-id="term-14">Eigentümern</button> helfen, wenn sie <button type="button" class="article-term" data-term-id="term-15">freie Flächen</button> als <button type="button" class="article-term article-term--default" data-term-id="term-16">Wohnraum</button> <button type="button" class="article-term" data-term-id="term-17">nutzen</button> wollen. Das kann auch nur für eine <button type="button" class="article-term" data-term-id="term-18">begrenzte Zeit</button> <button type="button" class="article-term" data-term-id="term-19">gelten</button>. Evers sagt, solche Projekte könnten schneller <button type="button" class="article-term" data-term-id="term-20">wirken</button> als sehr große <button type="button" class="article-term article-term--default" data-term-id="term-21">Bauvorhaben</button>. Denn dort <button type="button" class="article-term" data-term-id="term-22">dauern</button> Planung, <button type="button" class="article-term article-term--default" data-term-id="term-23">Genehmigungen</button> und Bau oft viele Jahre.

Auch auf den Dächern sieht die CDU viel Platz. Wenn Häuser <button type="button" class="article-term" data-term-id="term-24">zusätzliche Geschosse</button> bekommen, könnten theoretisch <button type="button" class="article-term" data-term-id="term-25">zehntausende</button> Wohnungen <button type="button" class="article-term" data-term-id="term-26">entstehen</button>. <button type="button" class="article-term" data-term-id="term-27">Bisher</button> <button type="button" class="article-term" data-term-id="term-28">scheiterten</button> solche Pläne aber oft an Regeln, langen <button type="button" class="article-term" data-term-id="term-29">Verfahren</button> und hohen Kosten. Die CDU will <button type="button" class="article-term" data-term-id="term-30">deshalb</button> <button type="button" class="article-term" data-term-id="term-31">vorhandene</button> Straßen, <button type="button" class="article-term" data-term-id="term-32">Leitungen</button> und Schulen besser <button type="button" class="article-term" data-term-id="term-17">nutzen</button>. So soll <button type="button" class="article-term" data-term-id="term-33">dichter gebaut</button> werden, ohne immer neue große Flächen zu <button type="button" class="article-term" data-term-id="term-34">erschließen</button>.

<button type="button" class="article-term" data-term-id="term-35">Klar</button> <button type="button" class="article-term" data-term-id="term-36">lehnt</button> Evers die <button type="button" class="article-term article-term--default" data-term-id="term-37">Vergesellschaftung</button> großer <button type="button" class="article-term article-term--default" data-term-id="term-38">Immobilienunternehmen</button> ab. Damit ist <button type="button" class="article-term" data-term-id="term-39">gemeint</button>, dass große <button type="button" class="article-term" data-term-id="term-40">Wohnungsfirmen</button> in <button type="button" class="article-term" data-term-id="term-41">öffentliches Eigentum</button> <button type="button" class="article-term" data-term-id="term-42">übergehen</button>. Ein <button type="button" class="article-term" data-term-id="term-43">Volksentscheid</button> dazu war in Berlin erfolgreich. <button type="button" class="article-term" data-term-id="term-44">Trotzdem</button> will die CDU diese <button type="button" class="article-term" data-term-id="term-45">Forderung</button> nicht <button type="button" class="article-term" data-term-id="term-46">umsetzen</button>. <button type="button" class="article-term" data-term-id="term-47">Aus ihrer Sicht</button> würde das Investoren <button type="button" class="article-term" data-term-id="term-48">unsicher machen</button>. Evers setzt <button type="button" class="article-term" data-term-id="term-30">deshalb</button> auf mehr <button type="button" class="article-term" data-term-id="term-49">Neubau</button> und <button type="button" class="article-term" data-term-id="term-50">verlässliche Regeln</button> für Eigentümer und Firmen.

Besonders <button type="button" class="article-term" data-term-id="term-51">umstritten</button> bleibt das Tempelhofer Feld. Die CDU möchte dort <button type="button" class="article-term" data-term-id="term-52">zumindest</button> <button type="button" class="article-term" data-term-id="term-53">am Rand</button> Wohnungen bauen. Im Jahr 2014 hatten die Berlinerinnen und Berliner in einem <button type="button" class="article-term" data-term-id="term-43">Volksentscheid</button> <button type="button" class="article-term" data-term-id="term-54">dagegen gestimmt</button>. <button type="button" class="article-term" data-term-id="term-44">Trotzdem</button> hält Evers an der Idee fest. Dort könnten nach CDU-Plänen <button type="button" class="article-term" data-term-id="term-55">bezahlbare Wohnungen</button> für <button type="button" class="article-term" data-term-id="term-56">bis zu</button> 50.000 Menschen <button type="button" class="article-term" data-term-id="term-26">entstehen</button>. Evers findet es <button type="button" class="article-term" data-term-id="term-57">schwer erklärbar</button>, wenn <button type="button" class="article-term" data-term-id="term-58">Innenhöfe</button> dichter <button type="button" class="article-term" data-term-id="term-59">bebaut</button> werden. <button type="button" class="article-term" data-term-id="term-60">Gleichzeitig</button> <button type="button" class="article-term" data-term-id="term-61">bleibe</button> eine große zentrale Fläche <button type="button" class="article-term" data-term-id="term-62">frei</button>.
