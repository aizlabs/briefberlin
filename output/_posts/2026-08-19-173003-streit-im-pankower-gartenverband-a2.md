Im Pankower <button type="button" class="article-term article-term--default" data-term-id="term-2">Gartenverband</button> gibt es wieder einen <button type="button" class="article-term article-term--default" data-term-id="term-1">Streit</button>. Die <button type="button" class="article-term" data-term-id="term-7">Mitglieder</button> <button type="button" class="article-term" data-term-id="term-8">wählten</button> im November 2025 eine neue <button type="button" class="article-term article-term--default" data-term-id="term-6">Leitung</button>. Gerda F. sagt: Sie wollte alte <button type="button" class="article-term" data-term-id="term-15">Geldprobleme</button> genau <button type="button" class="article-term" data-term-id="term-16">prüfen</button>. Deshalb steht der <button type="button" class="article-term" data-term-id="term-3">Verband</button> schon lange <button type="button" class="article-term" data-term-id="term-19">unter großem Druck</button>. Das ist ein <button type="button" class="article-term" data-term-id="term-25">Gericht</button> für einfache <button type="button" class="article-term" data-term-id="term-26">Fälle</button> im <button type="button" class="article-term" data-term-id="term-27">Bezirk</button>. Beide Male hat das <button type="button" class="article-term" data-term-id="term-25">Gericht</button> ihr zuerst <button type="button" class="article-term" data-term-id="term-28">recht gegeben</button>.

Gerda F. hat deshalb einen offiziellen <button type="button" class="article-term article-term--default" data-term-id="term-34">Widerspruch</button> geschrieben. Mit diesem <button type="button" class="article-term" data-term-id="term-35">Brief</button> <button type="button" class="article-term" data-term-id="term-36">akzeptiert</button> sie die Entscheidung nicht.

Gerda F. sagt: Das <button type="button" class="article-term" data-term-id="term-23">Treffen</button> war nicht fair. Ein möglicher <button type="button" class="article-term" data-term-id="term-37">Grund</button> ist eine <button type="button" class="article-term" data-term-id="term-38">Anzeige</button> wegen <button type="button" class="article-term article-term--default" data-term-id="term-39">Beleidigung</button>. <button type="button" class="article-term" data-term-id="term-40">Dabei</button> sagt jemand der Polizei: Eine Person hat mich <button type="button" class="article-term" data-term-id="term-41">beleidigt</button>.
