Der <button type="button" class="article-term" data-term-id="term-1">alte</button> Flughafen Tegel in Berlin <button type="button" class="article-term" data-term-id="term-2">bekommt</button> eine neue <button type="button" class="article-term" data-term-id="term-3">Aufgabe</button>. <button type="button" class="article-term" data-term-id="term-4">Seit</button> November 2020 <button type="button" class="article-term" data-term-id="term-5">fliegen</button> <button type="button" class="article-term" data-term-id="term-6">dort</button> keine normalen <button type="button" class="article-term" data-term-id="term-7">Passagiere</button> <button type="button" class="article-term" data-term-id="term-8">mehr</button> ab. Die Stadt <button type="button" class="article-term" data-term-id="term-9">macht aus</button> dem großen <button type="button" class="article-term article-term--default" data-term-id="term-10">Gelände</button> einen neuen <button type="button" class="article-term article-term--default" data-term-id="term-11">Stadtteil</button>.

Das <button type="button" class="article-term article-term--default" data-term-id="term-10">Gelände</button> ist <button type="button" class="article-term" data-term-id="term-12">etwa</button> 500 Hektar groß und sehr <button type="button" class="article-term" data-term-id="term-13">weit</button>. Das ist <button type="button" class="article-term" data-term-id="term-14">so groß wie</button> viele kleine Stadtteile <button type="button" class="article-term" data-term-id="term-15">zusammen</button>. <button type="button" class="article-term" data-term-id="term-16">Zuerst</button> <button type="button" class="article-term" data-term-id="term-17">ordnet</button> Berlin die alten <button type="button" class="article-term article-term--default" data-term-id="term-18">Flächen</button> <button type="button" class="article-term" data-term-id="term-6">dort</button> neu. <button type="button" class="article-term" data-term-id="term-19">Danach</button> <button type="button" class="article-term" data-term-id="term-20">bauen</button> <button type="button" class="article-term" data-term-id="term-21">Firmen</button> und <button type="button" class="article-term" data-term-id="term-22">Forscher</button> neue <button type="button" class="article-term" data-term-id="term-23">Häuser</button> bei den alten Flughafen-Gebäuden. Der neue <button type="button" class="article-term" data-term-id="term-24">Arbeitsort</button> <button type="button" class="article-term" data-term-id="term-25">heißt</button> Urban Tech Republic in Tegel.

Hier arbeiten Menschen <button type="button" class="article-term" data-term-id="term-26">später</button> an Technik für Städte. <button type="button" class="article-term" data-term-id="term-27">Zum Beispiel</button> <button type="button" class="article-term" data-term-id="term-28">geht es um</button> Energie, <button type="button" class="article-term article-term--default" data-term-id="term-29">Verkehr</button> und neue Ideen. <button type="button" class="article-term" data-term-id="term-30">Weiter</button> im <button type="button" class="article-term" data-term-id="term-31">Osten</button> <button type="button" class="article-term" data-term-id="term-32">wächst</button> das neue Schumacher Quartier. <button type="button" class="article-term" data-term-id="term-6">Dort</button> baut Berlin neue <button type="button" class="article-term article-term--default" data-term-id="term-33">Wohnungen</button> für viele Menschen. Auch <button type="button" class="article-term" data-term-id="term-34">Wege</button>, Schulen und <button type="button" class="article-term" data-term-id="term-35">Läden</button> <button type="button" class="article-term" data-term-id="term-36">gehören</button> <button type="button" class="article-term" data-term-id="term-26">später</button> dazu.

<button type="button" class="article-term" data-term-id="term-37">Außerdem</button> plant die Stadt viele <button type="button" class="article-term" data-term-id="term-38">grüne</button> <button type="button" class="article-term" data-term-id="term-39">Orte</button>. Es gibt Parks, <button type="button" class="article-term" data-term-id="term-40">Wiesen</button> und <button type="button" class="article-term" data-term-id="term-41">Plätze</button> zum <button type="button" class="article-term article-term--default" data-term-id="term-42">Ausruhen</button>. Der Plan ist <button type="button" class="article-term" data-term-id="term-43">einfach</button>: Der <button type="button" class="article-term article-term--default" data-term-id="term-11">Stadtteil</button> <button type="button" class="article-term" data-term-id="term-44">braucht</button> <button type="button" class="article-term" data-term-id="term-45">wenig</button> Energie und Wasser. Er <button type="button" class="article-term" data-term-id="term-46">nutzt</button> <button type="button" class="article-term" data-term-id="term-47">saubere</button> Energie und macht <button type="button" class="article-term" data-term-id="term-45">wenig</button> <button type="button" class="article-term article-term--default" data-term-id="term-48">schädliche</button> Gase. Tegel wird <button type="button" class="article-term" data-term-id="term-49">deshalb</button> ein Test für die Stadt <button type="button" class="article-term" data-term-id="term-50">von morgen</button>.
