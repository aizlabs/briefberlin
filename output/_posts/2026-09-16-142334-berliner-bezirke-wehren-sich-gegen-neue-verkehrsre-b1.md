In Berlin gibt es <button type="button" class="article-term" data-term-id="term-2">Streit</button> über neue Regeln für <button type="button" class="article-term" data-term-id="term-3">ruhige</button> Straßen. Die <button type="button" class="article-term article-term--default" data-term-id="term-4">Verkehrsverwaltung</button> des Senats hat einen <button type="button" class="article-term article-term--default" data-term-id="term-5">Entwurf</button> geschrieben. Er <button type="button" class="article-term" data-term-id="term-6">betrifft</button> <button type="button" class="article-term" data-term-id="term-7">Maßnahmen</button> zur <button type="button" class="article-term article-term--default" data-term-id="term-8">Verkehrsberuhigung</button> in <button type="button" class="article-term" data-term-id="term-9">Nebenstraßen</button>, also in kleineren Straßen <button type="button" class="article-term" data-term-id="term-10">abseits</button> der <button type="button" class="article-term" data-term-id="term-11">Hauptstraßen</button>. Viele <button type="button" class="article-term" data-term-id="term-1">Bezirke</button> sehen darin zu starke <button type="button" class="article-term article-term--default" data-term-id="term-12">Vorgaben</button> <button type="button" class="article-term" data-term-id="term-13">von oben</button>.

Acht von zwölf <button type="button" class="article-term" data-term-id="term-14">Bezirksämtern</button> <button type="button" class="article-term" data-term-id="term-15">lehnen</button> den <button type="button" class="article-term article-term--default" data-term-id="term-5">Entwurf</button> von Verkehrssenatorin Ute Bonde ab. Bonde <button type="button" class="article-term" data-term-id="term-16">gehört zur</button> CDU und ist im Senat für Verkehr <button type="button" class="article-term" data-term-id="term-17">zuständig</button>. Andere <button type="button" class="article-term" data-term-id="term-1">Bezirke</button> sprechen von großen <button type="button" class="article-term" data-term-id="term-18">rechtlichen</button> und <button type="button" class="article-term" data-term-id="term-19">fachlichen</button> <button type="button" class="article-term article-term--default" data-term-id="term-20">Bedenken</button>. Damit gibt es <button type="button" class="article-term" data-term-id="term-21">breiten</button> <button type="button" class="article-term" data-term-id="term-22">Widerstand</button> gegen die <button type="button" class="article-term" data-term-id="term-23">geplante</button> <button type="button" class="article-term article-term--default" data-term-id="term-24">Verwaltungsvorschrift</button>. Eine solche <button type="button" class="article-term" data-term-id="term-25">Vorschrift</button> sagt <button type="button" class="article-term" data-term-id="term-26">Verwaltungen</button>, wie sie bestimmte <button type="button" class="article-term" data-term-id="term-27">Entscheidungen treffen</button> sollen.

Rechtliche <button type="button" class="article-term article-term--default" data-term-id="term-20">Bedenken</button> bedeuten: Die <button type="button" class="article-term" data-term-id="term-1">Bezirke</button> <button type="button" class="article-term" data-term-id="term-28">zweifeln</button>, ob der Senat das <button type="button" class="article-term" data-term-id="term-29">entscheiden</button> darf. Fachliche <button type="button" class="article-term article-term--default" data-term-id="term-20">Bedenken</button> betreffen die <button type="button" class="article-term" data-term-id="term-30">praktische Arbeit</button> auf den Straßen. Die <button type="button" class="article-term" data-term-id="term-1">Bezirke</button> kennen ihre <button type="button" class="article-term" data-term-id="term-31">Kieze</button> und die <button type="button" class="article-term" data-term-id="term-32">täglichen</button> Probleme dort.

Die <button type="button" class="article-term" data-term-id="term-1">Bezirke</button> <button type="button" class="article-term" data-term-id="term-33">bekamen</button> den <button type="button" class="article-term article-term--default" data-term-id="term-5">Entwurf</button> Ende August. Danach sollten sie <button type="button" class="article-term" data-term-id="term-34">innerhalb von</button> zwei Wochen ihre <button type="button" class="article-term" data-term-id="term-35">Meinung abgeben</button>. Diese kurze <button type="button" class="article-term article-term--default" data-term-id="term-36">Frist</button> <button type="button" class="article-term" data-term-id="term-37">sorgte</button> <button type="button" class="article-term" data-term-id="term-38">zusätzlich</button> für Kritik, weil die <button type="button" class="article-term" data-term-id="term-1">Bezirke</button> viele Punkte <button type="button" class="article-term" data-term-id="term-39">prüfen</button> mussten. Es geht zum Beispiel um <button type="button" class="article-term article-term--default" data-term-id="term-40">Poller</button>, also <button type="button" class="article-term" data-term-id="term-41">feste Pfosten</button> auf der Straße. Sie können Autos stoppen und Wohngebiete sicherer oder ruhiger machen.

Der wichtigste <button type="button" class="article-term" data-term-id="term-42">Streitpunkt</button> ist die <button type="button" class="article-term article-term--default" data-term-id="term-43">Zuständigkeit</button>. Die <button type="button" class="article-term" data-term-id="term-1">Bezirke</button> planen oft selbst, wie sie Verkehr in ihren <button type="button" class="article-term" data-term-id="term-9">Nebenstraßen</button> <button type="button" class="article-term" data-term-id="term-44">ordnen</button>. Der Senat will ihnen nun <button type="button" class="article-term" data-term-id="term-45">offenbar</button> <button type="button" class="article-term" data-term-id="term-46">genauere</button> Regeln geben. <button type="button" class="article-term" data-term-id="term-47">Deshalb</button> fragen die <button type="button" class="article-term" data-term-id="term-1">Bezirke</button>, wie weit der Senat dabei gehen darf. Sie <button type="button" class="article-term" data-term-id="term-48">fürchten</button>, dass sie <button type="button" class="article-term" data-term-id="term-49">vor Ort</button> weniger <button type="button" class="article-term" data-term-id="term-50">frei handeln</button> können. <button type="button" class="article-term" data-term-id="term-51">Gleichzeitig</button> muss der Senat Regeln für ganz Berlin <button type="button" class="article-term" data-term-id="term-52">beachten</button>.

Noch ist die neue <button type="button" class="article-term" data-term-id="term-25">Vorschrift</button> nicht <button type="button" class="article-term" data-term-id="term-53">beschlossen</button>. Zuerst prüft die <button type="button" class="article-term article-term--default" data-term-id="term-4">Verkehrsverwaltung</button> die Antworten aus den Bezirken. Danach kann der <button type="button" class="article-term article-term--default" data-term-id="term-5">Entwurf</button> <button type="button" class="article-term" data-term-id="term-54">geändert</button> werden. Der Konflikt zeigt <button type="button" class="article-term" data-term-id="term-55">jedoch</button> schon jetzt ein größeres Problem. Berlin muss Verkehr sicherer und ruhiger machen, <button type="button" class="article-term" data-term-id="term-56">während</button> Bezirk und Senat um ihre Rollen <button type="button" class="article-term" data-term-id="term-57">streiten</button>.
