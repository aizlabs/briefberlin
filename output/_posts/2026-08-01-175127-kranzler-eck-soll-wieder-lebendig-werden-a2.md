Das Kranzler Eck <button type="button" class="article-term" data-term-id="term-1">liegt</button> am Kurfürstendamm in Berlin. Viele Berliner <button type="button" class="article-term" data-term-id="term-2">nennen</button> diese große Straße kurz Ku’damm. Dort soll der Ort jetzt wieder <button type="button" class="article-term article-term--default" data-term-id="term-3">lebendiger</button> werden. Die Stadt <button type="button" class="article-term article-term--default" data-term-id="term-4">schützt</button> die alten <button type="button" class="article-term" data-term-id="term-5">Gebäude</button>, weil sie wichtig für Berlin sind. Vom 28. August bis 6. September gibt es dort <button type="button" class="article-term" data-term-id="term-6">jeden Abend</button> Filme. Die Filme <button type="button" class="article-term" data-term-id="term-7">beginnen</button> um 19 Uhr <button type="button" class="article-term article-term--default" data-term-id="term-8">unter freiem Himmel</button>.

<button type="button" class="article-term" data-term-id="term-9">Zuerst</button> <button type="button" class="article-term" data-term-id="term-10">ändert sich</button> der Innenhof an diesem Ort <button type="button" class="article-term" data-term-id="term-11">deutlich</button>. Seit 2001 haben dort zwei große <button type="button" class="article-term" data-term-id="term-12">Käfige</button> für <button type="button" class="article-term" data-term-id="term-13">Vögel</button> <button type="button" class="article-term" data-term-id="term-14">gestanden</button>. Jetzt sind sie <button type="button" class="article-term" data-term-id="term-15">weg</button>. Die letzten <button type="button" class="article-term article-term--default" data-term-id="term-16">Sittiche</button> leben jetzt in einer <button type="button" class="article-term" data-term-id="term-17">Vogelstation</button> in Hessen. <button type="button" class="article-term article-term--default" data-term-id="term-16">Sittiche</button> sind kleine <button type="button" class="article-term" data-term-id="term-18">Papageien</button>. <button type="button" class="article-term" data-term-id="term-19">Danach</button> <button type="button" class="article-term" data-term-id="term-20">bekommt</button> der Hof viele <button type="button" class="article-term" data-term-id="term-21">Pflanzen</button> und mehr <button type="button" class="article-term" data-term-id="term-22">Platz</button>. Dort sollen <button type="button" class="article-term" data-term-id="term-23">Treffen</button> mit <button type="button" class="article-term" data-term-id="term-24">bis zu</button> 300 <button type="button" class="article-term" data-term-id="term-25">Gästen</button> <button type="button" class="article-term" data-term-id="term-26">möglich</button> sein. Firmen können dort <button type="button" class="article-term" data-term-id="term-27">Feste</button> machen, und Menschen können Yoga lernen.

Auch das bekannte Café Kranzler soll im nächsten <button type="button" class="article-term" data-term-id="term-29">Herbst</button> <button type="button" class="article-term article-term--default" data-term-id="term-28">zurückkommen</button>. Seit <button type="button" class="article-term" data-term-id="term-30">etwa zwei Jahren</button> ist es nicht mehr <button type="button" class="article-term" data-term-id="term-31">offen</button>. Gäste sollen wieder <button type="button" class="article-term" data-term-id="term-32">draußen</button> am Ku’damm sitzen können. Sie sitzen dann unter <button type="button" class="article-term" data-term-id="term-33">rot-weiß</button> <button type="button" class="article-term" data-term-id="term-34">gestreiften</button> <button type="button" class="article-term" data-term-id="term-35">Dächern</button> aus <button type="button" class="article-term" data-term-id="term-36">Stoff</button>. Auch auf einem Balkon gibt es dann <button type="button" class="article-term" data-term-id="term-37">Plätze</button>. Noch gibt es keinen Namen für die neue Café-Firma. <button type="button" class="article-term" data-term-id="term-38">Außerdem</button> <button type="button" class="article-term" data-term-id="term-20">bekommt</button> das Dach <button type="button" class="article-term" data-term-id="term-21">Pflanzen</button>, <button type="button" class="article-term" data-term-id="term-39">Gräser</button> und <button type="button" class="article-term" data-term-id="term-40">Kräuter</button>.

Ein wichtiges Problem <button type="button" class="article-term" data-term-id="term-41">bleibt</button> aber weiter <button type="button" class="article-term" data-term-id="term-31">offen</button>. Das <button type="button" class="article-term" data-term-id="term-42">frühere</button> <button type="button" class="article-term article-term--default" data-term-id="term-43">Kaufhaus</button> Bilka steht seit 2020 <button type="button" class="article-term article-term--default" data-term-id="term-44">leer</button>. <button type="button" class="article-term" data-term-id="term-19">Danach</button> hat dort Karstadt Sports <button type="button" class="article-term" data-term-id="term-45">Sport-Sachen</button> <button type="button" class="article-term" data-term-id="term-46">verkauft</button>. Es gibt einen Plan für Kultur und <button type="button" class="article-term" data-term-id="term-47">Veranstaltungen</button>. Aber der Start im <button type="button" class="article-term" data-term-id="term-48">Frühjahr</button> 2025 hat nicht <button type="button" class="article-term" data-term-id="term-49">geklappt</button>. Rossmann will im <button type="button" class="article-term" data-term-id="term-29">Herbst</button> <button type="button" class="article-term" data-term-id="term-50">Räume</button> in der <button type="button" class="article-term" data-term-id="term-51">Nähe</button> <button type="button" class="article-term" data-term-id="term-52">öffnen</button>. PayPal hat seine deutsche <button type="button" class="article-term" data-term-id="term-53">Hauptstelle</button> schon in das <button type="button" class="article-term" data-term-id="term-54">Hochhaus</button> am Ku’damm <button type="button" class="article-term" data-term-id="term-55">gebracht</button>. Aber niemand weiß, was mit dem alten <button type="button" class="article-term article-term--default" data-term-id="term-43">Kaufhaus</button> <button type="button" class="article-term" data-term-id="term-56">passiert</button>.
