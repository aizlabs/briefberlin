Im August haben Kriminelle die Computer von der Berliner <button type="button" class="article-term article-term--default" data-term-id="term-2">Verwaltung</button> <button type="button" class="article-term" data-term-id="term-3">angegriffen</button>. Sie haben dabei sehr viele Daten <button type="button" class="article-term" data-term-id="term-4">gestohlen</button>. Jetzt ist klar: <button type="button" class="article-term" data-term-id="term-5">Darunter</button> sind private Daten von fast 17.000 <button type="button" class="article-term article-term--default" data-term-id="term-1">Mietern</button>.

Die Daten kommen aus zwei <button type="button" class="article-term" data-term-id="term-6">Ämtern</button>, für <button type="button" class="article-term" data-term-id="term-7">Verkehr</button> und für Bauen. Die Kriminellen haben der Stadt eine <button type="button" class="article-term article-term--default" data-term-id="term-8">Frist</button> gegeben. Nach der <button type="button" class="article-term article-term--default" data-term-id="term-8">Frist</button> haben sie die Daten ins Darknet gestellt. Das ist ein <button type="button" class="article-term" data-term-id="term-9">versteckter</button> Teil vom Internet. Dort liegen jetzt viele <button type="button" class="article-term article-term--default" data-term-id="term-10">Anträge</button> aus den Jahren 2016 bis 2020. Mit diesen Anträgen bekommen Menschen Geld für ihre <button type="button" class="article-term" data-term-id="term-11">Miete</button>. Sie <button type="button" class="article-term" data-term-id="term-12">wohnen</button> in <button type="button" class="article-term article-term--default" data-term-id="term-13">Sozialwohnungen</button>. Das sind <button type="button" class="article-term" data-term-id="term-14">günstige</button> Wohnungen für Menschen mit wenig Geld.

In den Anträgen stehen Namen, <button type="button" class="article-term" data-term-id="term-15">Geburtstage</button> und Adressen. Oft stehen dort auch die <button type="button" class="article-term" data-term-id="term-11">Miete</button> und das <button type="button" class="article-term" data-term-id="term-16">Einkommen</button>. Bei 2423 Menschen steht: Sie haben eine <button type="button" class="article-term" data-term-id="term-17">schwere Behinderung</button>. <button type="button" class="article-term" data-term-id="term-18">Außerdem</button> sind die Bankdaten von fast 4000 Menschen dabei. Manche Menschen haben auch über <button type="button" class="article-term" data-term-id="term-19">Krankheiten</button>, Depressionen oder <button type="button" class="article-term" data-term-id="term-20">tote</button> Familienmitglieder geschrieben. Ein Mann hat geschrieben: Ohne meine Wohnung habe ich kein <button type="button" class="article-term" data-term-id="term-21">Zuhause</button> mehr.

<button type="button" class="article-term" data-term-id="term-22">Wahrscheinlich</button> ist eine <button type="button" class="article-term" data-term-id="term-23">einzige</button> E-Mail der <button type="button" class="article-term" data-term-id="term-24">Grund</button> für das Problem. Im Jahr 2020 hat eine Bank die Arbeit mit den Anträgen <button type="button" class="article-term" data-term-id="term-25">übernommen</button>. Danach hat ein <button type="button" class="article-term" data-term-id="term-26">Mitarbeiter</button> von der <button type="button" class="article-term article-term--default" data-term-id="term-2">Verwaltung</button> drei <button type="button" class="article-term" data-term-id="term-27">Tabellen</button> mit den Daten an einen Kollegen <button type="button" class="article-term" data-term-id="term-28">geschickt</button>. <button type="button" class="article-term" data-term-id="term-29">Niemand</button> weiß, warum. <button type="button" class="article-term" data-term-id="term-30">Deshalb</button> waren die Daten im Computernetz von der Stadt. Es ist noch <button type="button" class="article-term" data-term-id="term-31">unklar</button>: Hat die Stadt die Mieter informiert?

Eine <button type="button" class="article-term" data-term-id="term-32">Anwältin</button> sagt: Die Stadt hat einen schweren <button type="button" class="article-term" data-term-id="term-33">Fehler</button> beim <button type="button" class="article-term article-term--default" data-term-id="term-34">Datenschutz</button> gemacht. Jede Person kann mehrere Tausend Euro bekommen. Bei Familien sind es schnell mehr als 10.000 Euro. Die <button type="button" class="article-term" data-term-id="term-32">Anwältin</button> glaubt: Viele Mieter gehen zusammen <button type="button" class="article-term" data-term-id="term-35">vor Gericht</button>. Aber das Geld bringt die privaten Daten nicht zurück.
