Im Berliner Bezirk Steglitz-Zehlendorf gibt es viele <button type="button" class="article-term article-term--default" data-term-id="term-1">Einkaufsstraßen</button>. Manche <button type="button" class="article-term" data-term-id="term-2">Läden</button> dort sind <button type="button" class="article-term" data-term-id="term-3">leer</button> und <button type="button" class="article-term" data-term-id="term-4">bringen kein Leben</button> in die Straße. Der Bezirk prüft jetzt eine neue Internet-Seite <button type="button" class="article-term" data-term-id="term-5">gegen</button> dieses Problem.

<button type="button" class="article-term" data-term-id="term-6">Zuerst</button> hat die <button type="button" class="article-term article-term--default" data-term-id="term-7">Bezirksverordnetenversammlung</button> im Bezirk einen <button type="button" class="article-term" data-term-id="term-8">Auftrag</button> <button type="button" class="article-term" data-term-id="term-9">beschlossen</button>. Die <button type="button" class="article-term article-term--default" data-term-id="term-7">Bezirksverordnetenversammlung</button> ist das <button type="button" class="article-term" data-term-id="term-10">gewählte</button> Parlament im Bezirk. Es sagt: Das <button type="button" class="article-term article-term--default" data-term-id="term-11">Bezirksamt</button> soll eine digitale Seite prüfen. Die Seite soll <button type="button" class="article-term article-term--default" data-term-id="term-12">freie Ladenräume</button> <button type="button" class="article-term" data-term-id="term-13">sammeln</button> und <button type="button" class="article-term" data-term-id="term-14">zeigen</button>. Dann finden interessierte Menschen <button type="button" class="article-term" data-term-id="term-15">schneller</button> einen <button type="button" class="article-term" data-term-id="term-16">passenden Raum</button>.

Auch <button type="button" class="article-term" data-term-id="term-17">Bürgerinnen und Bürger</button> können auf der Seite helfen. Wenn sie einen leeren Laden sehen, <button type="button" class="article-term" data-term-id="term-18">melden</button> sie ihn dort. <button type="button" class="article-term article-term--default" data-term-id="term-19">Eigentümer</button> können dort sagen: Dieser Raum ist frei. <button type="button" class="article-term" data-term-id="term-20">Unternehmen</button>, <button type="button" class="article-term article-term--default" data-term-id="term-21">Handwerker</button> oder Gruppen schreiben dort: Wir <button type="button" class="article-term" data-term-id="term-22">suchen</button> einen Raum. <button type="button" class="article-term" data-term-id="term-23">Deshalb</button> kommen <button type="button" class="article-term" data-term-id="term-24">Anbieter</button> und <button type="button" class="article-term" data-term-id="term-25">suchende Menschen</button> <button type="button" class="article-term" data-term-id="term-26">leichter</button> zusammen.

<button type="button" class="article-term" data-term-id="term-27">Außerdem</button> gibt es <button type="button" class="article-term article-term--default" data-term-id="term-28">Vorbilder</button> in anderen deutschen <button type="button" class="article-term" data-term-id="term-29">Städten</button>. Dort nutzen die Städte schon <button type="button" class="article-term" data-term-id="term-30">ähnliche</button> Internet-Seiten mit <button type="button" class="article-term" data-term-id="term-31">Karten</button>. Auf einer <button type="button" class="article-term" data-term-id="term-32">Karte</button> sieht man dann leere Räume. So wissen neue <button type="button" class="article-term" data-term-id="term-33">Geschäfte</button> <button type="button" class="article-term" data-term-id="term-15">schneller</button>, wo ein Laden frei ist. <button type="button" class="article-term" data-term-id="term-34">Am Ende</button> kann das den <button type="button" class="article-term article-term--default" data-term-id="term-1">Einkaufsstraßen</button> im Bezirk helfen.
