Die juristische Dissertation <button type="button" class="article-term" data-term-id="term-8">entstand</button> 2005 an der Universität Köln. Nach Webers Ansicht hat Badenberg <button type="button" class="article-term" data-term-id="term-9">fremde Texte</button> zu stark <button type="button" class="article-term" data-term-id="term-10">übernommen</button>.

Der Fall ist politisch <button type="button" class="article-term" data-term-id="term-11">heikel</button>. Badenberg <button type="button" class="article-term" data-term-id="term-12">kandidiert</button> für einen <button type="button" class="article-term" data-term-id="term-13">Sitz</button> im Berliner Abgeordnetenhaus, also im <button type="button" class="article-term" data-term-id="term-14">Landesparlament</button>. Badenberg weist den <button type="button" class="article-term" data-term-id="term-17">Vorwurf</button> <button type="button" class="article-term" data-term-id="term-18">bisher</button> zurück. <button type="button" class="article-term" data-term-id="term-19">Nach eigenen Angaben</button> hat sie die Universität Köln um eine Prüfung <button type="button" class="article-term" data-term-id="term-20">gebeten</button>.

Solche <button type="button" class="article-term" data-term-id="term-23">Verfahren</button> <button type="button" class="article-term" data-term-id="term-24">dauern</button> oft ein bis zwei Jahre. An einer frühen Stelle sollen mehrere Absätze sehr nah an einer <button type="button" class="article-term" data-term-id="term-50">Vorlage</button> sein.

Der Fall zeigt auch Probleme an <button type="button" class="article-term" data-term-id="term-51">Hochschulen</button>. Programme zur <button type="button" class="article-term" data-term-id="term-52">Plagiatsprüfung</button> finden <button type="button" class="article-term" data-term-id="term-53">zwar</button> <button type="button" class="article-term" data-term-id="term-54">ähnliche</button> Texte, aber sie <button type="button" class="article-term" data-term-id="term-55">irren</button> manchmal. Sie melden <button type="button" class="article-term" data-term-id="term-56">harmlose Ähnlichkeiten</button> und <button type="button" class="article-term" data-term-id="term-57">übersehen</button> wichtige <button type="button" class="article-term" data-term-id="term-58">Übernahmen</button>. Deshalb brauchen Universitäten eine genaue Prüfung <button type="button" class="article-term" data-term-id="term-59">im Zusammenhang</button>. Kritiker sagen außerdem, dass viele <button type="button" class="article-term" data-term-id="term-51">Hochschulen</button> zu wenig Personal für solche <button type="button" class="article-term" data-term-id="term-60">Untersuchungen</button> haben. Kritiker sehen <button type="button" class="article-term" data-term-id="term-61">zudem</button> <button type="button" class="article-term" data-term-id="term-62">Lücken</button> bei <button type="button" class="article-term" data-term-id="term-63">Beratungsstellen</button> für gute wissenschaftliche Praxis in Berlin. Bis Köln <button type="button" class="article-term" data-term-id="term-64">entscheidet</button>, bleibt der <button type="button" class="article-term" data-term-id="term-65">Schaden</button> für Badenberg schwer <button type="button" class="article-term" data-term-id="term-66">einschätzbar</button>.
