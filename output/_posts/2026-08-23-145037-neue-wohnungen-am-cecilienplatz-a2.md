Am Cecilienplatz in Berlin-Marzahn-Hellersdorf hat der Abriss <button type="button" class="article-term" data-term-id="term-1">begonnen</button>. Dort <button type="button" class="article-term" data-term-id="term-2">steht</button> <button type="button" class="article-term" data-term-id="term-3">seit Jahren</button> ein altes kleines <button type="button" class="article-term" data-term-id="term-4">Einkaufszentrum</button> <button type="button" class="article-term" data-term-id="term-5">leer</button>. An diesem <button type="button" class="article-term" data-term-id="term-6">Ort</button> will die <button type="button" class="article-term" data-term-id="term-7">Firma</button> Primus Immobilien AG <button type="button" class="article-term" data-term-id="term-8">mehr als</button> 200 <button type="button" class="article-term article-term--default" data-term-id="term-9">Mietwohnungen</button> <button type="button" class="article-term" data-term-id="term-10">bauen</button>.

Ein großer Bagger <button type="button" class="article-term" data-term-id="term-11">arbeitet</button> jetzt am U-Bahnhof Kaulsdorf-Nord. <button type="button" class="article-term" data-term-id="term-12">Früher</button> gab es dort <button type="button" class="article-term" data-term-id="term-13">Geschäfte</button>, einen <button type="button" class="article-term" data-term-id="term-14">Friseur</button> und eine Bibliothek. Die drei alten Häuser <button type="button" class="article-term" data-term-id="term-15">sollen</button> in den nächsten Monaten <button type="button" class="article-term article-term--default" data-term-id="term-16">verschwinden</button>. <button type="button" class="article-term" data-term-id="term-17">Danach</button> will die <button type="button" class="article-term" data-term-id="term-7">Firma</button> drei neue <button type="button" class="article-term" data-term-id="term-18">Wohnhäuser</button> <button type="button" class="article-term" data-term-id="term-10">bauen</button>.

Der Platz war <button type="button" class="article-term" data-term-id="term-19">lange</button> ein Problem für den <button type="button" class="article-term article-term--default" data-term-id="term-20">Bezirk</button>. Frühere <button type="button" class="article-term" data-term-id="term-21">Besitzer</button> wollten auch <button type="button" class="article-term article-term--default" data-term-id="term-22">abreißen</button> und neu <button type="button" class="article-term" data-term-id="term-10">bauen</button>. Aber sie haben <button type="button" class="article-term" data-term-id="term-23">am Ende</button> fast nichts <button type="button" class="article-term" data-term-id="term-24">geschafft</button>. Die alten Häuser sahen immer <button type="button" class="article-term" data-term-id="term-25">schlechter</button> aus. Manchmal gab es dort Feuer, weil Menschen <button type="button" class="article-term" data-term-id="term-26">Feuer gelegt</button> haben. <button type="button" class="article-term" data-term-id="term-27">Deshalb</button> hat das <button type="button" class="article-term" data-term-id="term-28">Bezirksamt</button> <button type="button" class="article-term" data-term-id="term-29">nach und nach</button> <button type="button" class="article-term" data-term-id="term-30">Eingänge</button> <button type="button" class="article-term" data-term-id="term-31">geschlossen</button>.

Im Mai 2026 hat Primus Immobilien AG zwei <button type="button" class="article-term article-term--default" data-term-id="term-32">Grundstücke</button> gekauft. Ein <button type="button" class="article-term" data-term-id="term-33">weiteres</button> Grundstück soll im August noch <button type="button" class="article-term" data-term-id="term-34">dazukommen</button>. Der <button type="button" class="article-term" data-term-id="term-35">Bau</button> der Wohnungen soll im <button type="button" class="article-term" data-term-id="term-36">Frühling</button> 2027 beginnen. Ende 2029 <button type="button" class="article-term" data-term-id="term-15">sollen</button> die Wohnungen dann <button type="button" class="article-term" data-term-id="term-37">fertig</button> sein. Es soll Wohnungen mit einem bis vier <button type="button" class="article-term" data-term-id="term-38">Zimmern</button> geben.

Die <button type="button" class="article-term" data-term-id="term-7">Firma</button> plant keine <button type="button" class="article-term article-term--default" data-term-id="term-39">Sozialwohnungen</button> für dieses Projekt. Das sind <button type="button" class="article-term" data-term-id="term-40">billigere</button> Wohnungen mit <button type="button" class="article-term" data-term-id="term-41">festen Regeln</button> vom Staat. Die Stadt hat <button type="button" class="article-term" data-term-id="term-12">früher</button> schon Ja zum <button type="button" class="article-term" data-term-id="term-35">Bau</button> gesagt. In dieser <button type="button" class="article-term" data-term-id="term-42">Erlaubnis</button> stehen <button type="button" class="article-term" data-term-id="term-43">solche</button> Regeln vom Staat nicht.

Die <button type="button" class="article-term" data-term-id="term-44">Höhe</button> der <button type="button" class="article-term" data-term-id="term-45">Mieten</button> ist noch nicht <button type="button" class="article-term" data-term-id="term-46">klar</button>. Die <button type="button" class="article-term" data-term-id="term-7">Firma</button> sagt: Neues <button type="button" class="article-term" data-term-id="term-10">Bauen</button> <button type="button" class="article-term" data-term-id="term-47">kostet</button> viel Geld. Aber sie <button type="button" class="article-term" data-term-id="term-48">nennt</button> das Projekt kein großes Luxus-Projekt. <button type="button" class="article-term" data-term-id="term-49">Unten</button> in den Häusern <button type="button" class="article-term" data-term-id="term-15">sollen</button> <button type="button" class="article-term" data-term-id="term-50">Läden</button>, Restaurants und ein Café kommen. So kann der Platz <button type="button" class="article-term" data-term-id="term-51">wieder</button> wichtig für die <button type="button" class="article-term" data-term-id="term-52">Nachbarschaft</button> werden.
