Die Deutsche Bahn macht neue Regeln für Alkohol. Sie <button type="button" class="article-term article-term--default" data-term-id="term-2">gelten</button> <button type="button" class="article-term" data-term-id="term-3">bald</button> auf allen <button type="button" class="article-term" data-term-id="term-1">Bahnhöfen</button> der Bahn in Deutschland. <button type="button" class="article-term" data-term-id="term-4">Bis Mitte Oktober</button> <button type="button" class="article-term" data-term-id="term-7">dürfen</button> <button type="button" class="article-term article-term--default" data-term-id="term-5">Reisende</button> <button type="button" class="article-term" data-term-id="term-6">dort</button> keinen Alkohol trinken. Sie <button type="button" class="article-term" data-term-id="term-7">dürfen</button> auch keine <button type="button" class="article-term" data-term-id="term-8">offenen Flaschen</button> oder <button type="button" class="article-term" data-term-id="term-9">Dosen</button> mit Alkohol <button type="button" class="article-term" data-term-id="term-10">tragen</button>.

In Berlin <button type="button" class="article-term" data-term-id="term-11">startet</button> die <button type="button" class="article-term" data-term-id="term-12">Regel</button> nicht <button type="button" class="article-term" data-term-id="term-13">überall</button> <button type="button" class="article-term" data-term-id="term-14">gleich</button>. <button type="button" class="article-term" data-term-id="term-15">Deshalb</button> gibt es <button type="button" class="article-term" data-term-id="term-16">besondere Fälle</button> an <button type="button" class="article-term" data-term-id="term-1">Bahnhöfen</button> zum <button type="button" class="article-term article-term--default" data-term-id="term-17">Umsteigen</button>. Ein Bahnhof zum <button type="button" class="article-term article-term--default" data-term-id="term-17">Umsteigen</button> ist ein Bahnhof mit vielen <button type="button" class="article-term" data-term-id="term-18">Zügen</button>. Viele Menschen <button type="button" class="article-term" data-term-id="term-19">wechseln</button> <button type="button" class="article-term" data-term-id="term-6">dort</button> von einem Zug in einen anderen Zug.

<button type="button" class="article-term" data-term-id="term-20">Seit</button> dem 1. Mai gilt die <button type="button" class="article-term" data-term-id="term-12">Regel</button> am Bahnhof Zoo und am Ostbahnhof. <button type="button" class="article-term" data-term-id="term-21">Ab</button> dem 1. September kommen der Hauptbahnhof und Gesundbrunnen <button type="button" class="article-term" data-term-id="term-22">dazu</button>. <button type="button" class="article-term" data-term-id="term-23">Danach</button> <button type="button" class="article-term" data-term-id="term-24">folgen</button> <button type="button" class="article-term" data-term-id="term-25">weitere</button> Stationen <button type="button" class="article-term article-term--default" data-term-id="term-26">nach und nach</button> in Berlin. <button type="button" class="article-term" data-term-id="term-27">Am Ende</button> soll die <button type="button" class="article-term" data-term-id="term-12">Regel</button> <button type="button" class="article-term" data-term-id="term-13">überall</button> bei der Bahn <button type="button" class="article-term article-term--default" data-term-id="term-2">gelten</button>.

Die Bahn hat <button type="button" class="article-term" data-term-id="term-28">etwa</button> 5400 Bahnhöfe in Deutschland. Die Bahn <button type="button" class="article-term" data-term-id="term-29">nennt</button> zwei <button type="button" class="article-term article-term--default" data-term-id="term-30">Gründe</button> für die neue <button type="button" class="article-term" data-term-id="term-12">Regel</button>. <button type="button" class="article-term" data-term-id="term-31">Zuerst</button> will sie mehr <button type="button" class="article-term" data-term-id="term-32">Sicherheit</button> auf den Bahnsteigen. <button type="button" class="article-term" data-term-id="term-33">Außerdem</button> will sie <button type="button" class="article-term" data-term-id="term-34">sauberere</button> <button type="button" class="article-term" data-term-id="term-35">Hallen</button> in den <button type="button" class="article-term" data-term-id="term-1">Bahnhöfen</button>. Wenn <button type="button" class="article-term" data-term-id="term-36">weniger</button> Menschen <button type="button" class="article-term" data-term-id="term-6">dort</button> trinken, gibt es <button type="button" class="article-term" data-term-id="term-37">vielleicht</button> <button type="button" class="article-term" data-term-id="term-36">weniger</button> <button type="button" class="article-term" data-term-id="term-38">Streit</button>. Auch <button type="button" class="article-term" data-term-id="term-39">Müll</button> <button type="button" class="article-term" data-term-id="term-40">durch</button> Flaschen und <button type="button" class="article-term" data-term-id="term-9">Dosen</button> soll <button type="button" class="article-term" data-term-id="term-36">weniger</button> <button type="button" class="article-term" data-term-id="term-41">werden</button>.
