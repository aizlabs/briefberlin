An der Charité in Berlin gibt es jetzt <button type="button" class="article-term article-term--default" data-term-id="term-1">Streit</button>. Die Charité ist ein großes <button type="button" class="article-term" data-term-id="term-2">Krankenhaus</button> in der Stadt. Pflegekräfte wollen bessere <button type="button" class="article-term article-term--default" data-term-id="term-3">Arbeitsbedingungen</button> und <button type="button" class="article-term" data-term-id="term-4">drohen</button> mit einem <button type="button" class="article-term article-term--default" data-term-id="term-5">Streik</button>.

<button type="button" class="article-term article-term--default" data-term-id="term-3">Arbeitsbedingungen</button> sind die Regeln und die Lage bei der Arbeit. Die Pflegekräfte sagen: Ihre Arbeit soll besser werden. Die <button type="button" class="article-term article-term--default" data-term-id="term-6">Gewerkschaft</button> Verdi <button type="button" class="article-term" data-term-id="term-7">unterstützt</button> viele Pflegekräfte in diesem <button type="button" class="article-term article-term--default" data-term-id="term-1">Streit</button>. Eine <button type="button" class="article-term article-term--default" data-term-id="term-6">Gewerkschaft</button> hilft <button type="button" class="article-term" data-term-id="term-8">Arbeitnehmern</button> bei Gesprächen mit dem <button type="button" class="article-term" data-term-id="term-9">Arbeitgeber</button>.

<button type="button" class="article-term" data-term-id="term-10">Zuerst</button> hat Verdi seine <button type="button" class="article-term" data-term-id="term-11">Mitglieder</button> an der Charité gefragt. Die Frage war: Seid ihr zu einem <button type="button" class="article-term article-term--default" data-term-id="term-5">Streik</button> <button type="button" class="article-term" data-term-id="term-12">bereit</button>? 98 Prozent der <button type="button" class="article-term" data-term-id="term-11">Mitglieder</button>, die <button type="button" class="article-term" data-term-id="term-13">mitgemacht</button> haben, haben Ja gesagt. Das sind <button type="button" class="article-term" data-term-id="term-14">fast</button> alle Menschen in dieser <button type="button" class="article-term" data-term-id="term-15">Gruppe</button>.

Ein <button type="button" class="article-term article-term--default" data-term-id="term-5">Streik</button> <button type="button" class="article-term" data-term-id="term-16">bedeutet</button>: Menschen arbeiten <button type="button" class="article-term" data-term-id="term-17">für eine Zeit</button> nicht. So machen sie <button type="button" class="article-term article-term--default" data-term-id="term-18">Druck</button> auf die <button type="button" class="article-term article-term--default" data-term-id="term-19">Leitung</button> der Charité. Hier geht es um einen <button type="button" class="article-term article-term--default" data-term-id="term-5">Streik</button> ohne <button type="button" class="article-term" data-term-id="term-20">festes Ende</button>. Er kann länger <button type="button" class="article-term" data-term-id="term-21">dauern</button>, wenn es keine <button type="button" class="article-term" data-term-id="term-22">Lösung</button> gibt.

Jetzt sprechen Verdi und die <button type="button" class="article-term article-term--default" data-term-id="term-19">Leitung</button> weiter <button type="button" class="article-term" data-term-id="term-23">miteinander</button>. Die <button type="button" class="article-term article-term--default" data-term-id="term-19">Leitung</button> <button type="button" class="article-term" data-term-id="term-24">entscheidet</button> viel über die Arbeit im <button type="button" class="article-term" data-term-id="term-2">Krankenhaus</button>. Wenn <button type="button" class="article-term" data-term-id="term-25">beide Seiten</button> keine <button type="button" class="article-term article-term--default" data-term-id="term-26">Einigung</button> finden, kann Verdi zum <button type="button" class="article-term article-term--default" data-term-id="term-5">Streik</button> <button type="button" class="article-term" data-term-id="term-27">aufrufen</button>. Das Ja der <button type="button" class="article-term" data-term-id="term-11">Mitglieder</button> gibt Verdi <button type="button" class="article-term" data-term-id="term-28">dafür</button> viel <button type="button" class="article-term" data-term-id="term-29">Kraft</button>. <button type="button" class="article-term" data-term-id="term-30">Deshalb</button> <button type="button" class="article-term" data-term-id="term-31">wächst</button> jetzt der <button type="button" class="article-term article-term--default" data-term-id="term-18">Druck</button> auf die <button type="button" class="article-term article-term--default" data-term-id="term-19">Leitung</button> der Charité.

Verdi nennt nicht, wie viele <button type="button" class="article-term" data-term-id="term-11">Mitglieder</button> es dort gibt. Aber auf vielen <button type="button" class="article-term" data-term-id="term-32">Stationen</button> arbeiten viele Pflegekräfte mit Verdi zusammen. Eine Station ist ein <button type="button" class="article-term" data-term-id="term-33">Bereich</button> in einem <button type="button" class="article-term" data-term-id="term-2">Krankenhaus</button>. <button type="button" class="article-term" data-term-id="term-30">Deshalb</button> ist das <button type="button" class="article-term" data-term-id="term-34">Ergebnis</button> für die <button type="button" class="article-term" data-term-id="term-35">Gespräche</button> wichtig.

- **Arbeitsbedingungen** - working conditions - Die Lage und Regeln bei der Arbeit.
- **Streik** - strike - Arbeiter arbeiten absichtlich nicht, um etwas zu erreichen.
- **Gewerkschaft** - trade union - Eine Gruppe, die Arbeitnehmer bei Problemen unterstützt.
- **Druck** - pressure - Starker Einfluss, damit jemand etwas tut.
- **Leitung** - management, leadership - Personen, die eine Organisation führen.
- **Einigung** - agreement - Wenn beide Seiten Ja zu einer Lösung sagen.
