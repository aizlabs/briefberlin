Im Berliner Norden <button type="button" class="article-term" data-term-id="term-1">sollen</button> neue Wohnungen <button type="button" class="article-term" data-term-id="term-2">entstehen</button>, doch der Start bleibt <button type="button" class="article-term" data-term-id="term-3">vorsichtig</button>. Auf der Elisabeth-Aue in Blankenfelde plant Berlin den ersten <button type="button" class="article-term article-term--default" data-term-id="term-4">Bauabschnitt</button> für Herbst 2026. Dort will die Stadt zuerst <button type="button" class="article-term" data-term-id="term-5">rund</button> 170 Wohnungen bauen. Damit beginnt das Projekt <button type="button" class="article-term" data-term-id="term-6">deutlich</button> kleiner, als <button type="button" class="article-term" data-term-id="term-7">frühere</button> <button type="button" class="article-term" data-term-id="term-8">Zielzahlen</button> <button type="button" class="article-term" data-term-id="term-9">erwarten ließen</button>.

Die großen <button type="button" class="article-term article-term--default" data-term-id="term-10">Wohnungsbaupläne</button> für den Norden der Stadt sind damit <button type="button" class="article-term" data-term-id="term-11">nicht vom Tisch</button>. Sie starten aber langsamer, und die erste <button type="button" class="article-term" data-term-id="term-12">Etappe</button> <button type="button" class="article-term" data-term-id="term-13">fällt kleiner aus</button>. Der <button type="button" class="article-term" data-term-id="term-14">Unterschied</button> zwischen dem langen Ziel und dem ersten Start ist groß. Er zeigt, dass die <button type="button" class="article-term" data-term-id="term-15">weitere</button> Planung noch viele Jahre brauchen wird.

Die Elisabeth-Aue ist heute vor allem <button type="button" class="article-term article-term--default" data-term-id="term-16">Ackerland</button> im Bezirk Pankow. Der Berliner Senat, also die <button type="button" class="article-term" data-term-id="term-17">Landesregierung</button> der Stadt, hält <button type="button" class="article-term" data-term-id="term-18">trotzdem</button> an einem großen Ziel fest. Langfristig soll dort ein neues <button type="button" class="article-term" data-term-id="term-20">Stadtquartier</button> mit <button type="button" class="article-term" data-term-id="term-19">bis zu</button> 5000 Wohnungen <button type="button" class="article-term" data-term-id="term-2">entstehen</button>. Neben Wohnungen braucht ein <button type="button" class="article-term" data-term-id="term-21">solches</button> <button type="button" class="article-term" data-term-id="term-22">Gebiet</button> auch Straßen, Schulen, Kitas und Grünflächen.

Für einen ersten Teil des Projekts gibt es bereits <button type="button" class="article-term article-term--default" data-term-id="term-23">Planungsrecht</button> für <button type="button" class="article-term" data-term-id="term-5">rund</button> 860 Wohnungen. Das heißt, die <button type="button" class="article-term" data-term-id="term-24">Behörden</button> haben die <button type="button" class="article-term" data-term-id="term-25">rechtliche</button> <button type="button" class="article-term" data-term-id="term-26">Grundlage</button> für diese Planungen <button type="button" class="article-term" data-term-id="term-27">geschaffen</button>. Dazu <button type="button" class="article-term" data-term-id="term-28">gehört</button> auch eine integrierte <button type="button" class="article-term" data-term-id="term-29">Sekundarschule</button>, also eine <button type="button" class="article-term" data-term-id="term-30">weiterführende Schule</button> für <button type="button" class="article-term" data-term-id="term-31">Jugendliche</button>. Der <button type="button" class="article-term" data-term-id="term-32">Baubeginn</button> im Jahr 2026 <button type="button" class="article-term" data-term-id="term-33">betrifft</button> <button type="button" class="article-term" data-term-id="term-34">jedoch</button> nicht alle 860 Wohnungen. Zuerst kommt nur ein kleiner <button type="button" class="article-term" data-term-id="term-35">Abschnitt</button> mit <button type="button" class="article-term" data-term-id="term-36">etwa</button> 170 Wohnungen.

<button type="button" class="article-term" data-term-id="term-36">Etwa</button> die <button type="button" class="article-term" data-term-id="term-37">Hälfte</button> der Wohnungen soll besondere Regeln für <button type="button" class="article-term" data-term-id="term-38">Miete</button> und <button type="button" class="article-term article-term--default" data-term-id="term-39">Vergabe</button> bekommen. Dann <button type="button" class="article-term" data-term-id="term-40">dürfen</button> die Mieten nicht frei <button type="button" class="article-term" data-term-id="term-41">steigen</button>. Außerdem gehen diese Wohnungen an Menschen, die <button type="button" class="article-term" data-term-id="term-42">bestimmte</button> <button type="button" class="article-term" data-term-id="term-43">soziale</button> <button type="button" class="article-term article-term--default" data-term-id="term-44">Voraussetzungen</button> <button type="button" class="article-term" data-term-id="term-45">erfüllen</button>. So will Berlin auch <button type="button" class="article-term" data-term-id="term-46">Haushalten</button> mit weniger Geld <button type="button" class="article-term" data-term-id="term-47">Wohnraum</button> <button type="button" class="article-term" data-term-id="term-48">anbieten</button>.

Der <button type="button" class="article-term" data-term-id="term-49">Zeitplan</button> zeigt <button type="button" class="article-term" data-term-id="term-34">jedoch</button>, wie schwierig große Wohnungsbauprojekte in Berlin bleiben. Viele <button type="button" class="article-term" data-term-id="term-50">Schritte</button> <button type="button" class="article-term" data-term-id="term-51">dauern lange</button>, <button type="button" class="article-term" data-term-id="term-53">bevor</button> die <button type="button" class="article-term" data-term-id="term-52">Bauarbeiten</button> wirklich beginnen können. <button type="button" class="article-term" data-term-id="term-54">Deshalb</button> <button type="button" class="article-term" data-term-id="term-55">rücken</button> die Pläne <button type="button" class="article-term" data-term-id="term-56">zwar</button> näher, geraten aber <button type="button" class="article-term" data-term-id="term-57">zugleich</button> <button type="button" class="article-term article-term--default" data-term-id="term-58">ins Stocken</button>. Für Pankow <button type="button" class="article-term" data-term-id="term-59">bedeutet</button> das: Das neue Quartier kommt, aber <button type="button" class="article-term" data-term-id="term-60">zunächst</button> nur in kleinen Schritten.
