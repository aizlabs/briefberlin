Die <button type="button" class="article-term" data-term-id="term-1">Regierung</button> von Berlin, der <button type="button" class="article-term article-term--default" data-term-id="term-2">Senat</button>, will den Jahnsportpark <button type="button" class="article-term" data-term-id="term-3">schneller</button> <button type="button" class="article-term article-term--default" data-term-id="term-4">umbauen</button>. Der Sportpark <button type="button" class="article-term" data-term-id="term-5">liegt</button> in Berlin im <button type="button" class="article-term" data-term-id="term-6">Stadtteil</button> Prenzlauer Berg. <button type="button" class="article-term" data-term-id="term-7">Schon</button> im August will die Stadt eine <button type="button" class="article-term article-term--default" data-term-id="term-8">Baufirma</button> <button type="button" class="article-term" data-term-id="term-9">wählen</button>. Diese Firma <button type="button" class="article-term" data-term-id="term-10">soll</button> das große Stadion neu bauen.

Die Stadt will aus dem ganzen Park einen <button type="button" class="article-term" data-term-id="term-11">Sportort</button> für alle machen. Dort sollen Menschen <button type="button" class="article-term" data-term-id="term-12">mit und ohne</button> <button type="button" class="article-term article-term--default" data-term-id="term-13">Behinderung</button> gut Sport machen können. Das neue Stadion <button type="button" class="article-term" data-term-id="term-14">bekommt</button> <button type="button" class="article-term" data-term-id="term-15">ungefähr</button> 20.000 <button type="button" class="article-term" data-term-id="term-16">Plätze</button> für <button type="button" class="article-term" data-term-id="term-17">Besucher</button>. <button type="button" class="article-term" data-term-id="term-18">Zuerst</button> haben <button type="button" class="article-term" data-term-id="term-19">Arbeiter</button> <button type="button" class="article-term" data-term-id="term-7">schon</button> alte <button type="button" class="article-term" data-term-id="term-20">gefährliche</button> <button type="button" class="article-term article-term--default" data-term-id="term-21">Baustoffe</button> <button type="button" class="article-term" data-term-id="term-22">entfernt</button>. <button type="button" class="article-term" data-term-id="term-23">Außerdem</button> haben sie zwei hohe Lampen für das Spielfeld <button type="button" class="article-term" data-term-id="term-24">abgebaut</button>.

Aber es gibt jetzt <button type="button" class="article-term" data-term-id="term-25">Kritik</button> aus der Berliner Politik. <button type="button" class="article-term" data-term-id="term-26">Seit</button> <button type="button" class="article-term" data-term-id="term-27">Ende</button> April können Firmen <button type="button" class="article-term article-term--default" data-term-id="term-28">Angebote</button> für den <button type="button" class="article-term" data-term-id="term-29">Bau</button> machen. <button type="button" class="article-term" data-term-id="term-30">Dafür</button> hatten die Firmen nur 60 Tage Zeit. <button type="button" class="article-term" data-term-id="term-31">Danach</button> muss eine Gruppe in der <button type="button" class="article-term article-term--default" data-term-id="term-32">Verwaltung</button> die <button type="button" class="article-term article-term--default" data-term-id="term-28">Angebote</button> <button type="button" class="article-term" data-term-id="term-33">prüfen</button>. <button type="button" class="article-term" data-term-id="term-30">Dafür</button> <button type="button" class="article-term" data-term-id="term-34">bleiben</button> nur <button type="button" class="article-term" data-term-id="term-35">wenige</button> Wochen, auch in der <button type="button" class="article-term" data-term-id="term-36">Ferienzeit</button>.

Die Partei Die Grünen <button type="button" class="article-term" data-term-id="term-37">kritisiert</button> den <button type="button" class="article-term article-term--default" data-term-id="term-2">Senat</button>. Sie sagt: Viele <button type="button" class="article-term" data-term-id="term-38">Fragen</button> zum ganzen Park sind noch <button type="button" class="article-term" data-term-id="term-39">offen</button>. <button type="button" class="article-term" data-term-id="term-40">Besonders</button> wichtig ist der dritte <button type="button" class="article-term" data-term-id="term-41">Teil</button> des Baus. Dort plant die Stadt Sporthallen, freie <button type="button" class="article-term article-term--default" data-term-id="term-42">Flächen</button> und <button type="button" class="article-term" data-term-id="term-43">Orte</button> zum Treffen. Schulen und <button type="button" class="article-term" data-term-id="term-44">Vereine</button> <button type="button" class="article-term" data-term-id="term-45">brauchen</button> diese <button type="button" class="article-term article-term--default" data-term-id="term-42">Flächen</button>, nicht nur das große Stadion.

Auch das <button type="button" class="article-term" data-term-id="term-46">Geld</button> ist ein großes Thema. <button type="button" class="article-term" data-term-id="term-47">Früher</button> <button type="button" class="article-term" data-term-id="term-48">sprach</button> die Stadt von <button type="button" class="article-term" data-term-id="term-49">etwa</button> 100 Millionen Euro. Jetzt <button type="button" class="article-term" data-term-id="term-50">rechnet</button> sie mit fast 270 Millionen Euro. <button type="button" class="article-term" data-term-id="term-51">Deshalb</button> hat die Stadt einige <button type="button" class="article-term" data-term-id="term-52">Pläne</button> kleiner gemacht. Es gibt keine <button type="button" class="article-term" data-term-id="term-53">Tennishalle</button>, und das <button type="button" class="article-term" data-term-id="term-54">Zentrum</button> für Treffen wird kleiner. Nach dem Plan <button type="button" class="article-term" data-term-id="term-10">soll</button> das Stadion im Jahr 2028 <button type="button" class="article-term" data-term-id="term-55">fertig</button> sein. Die anderen Arbeiten sollen bis 2030 <button type="button" class="article-term" data-term-id="term-55">fertig</button> sein.
